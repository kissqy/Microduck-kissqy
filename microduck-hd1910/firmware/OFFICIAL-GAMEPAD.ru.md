# Геймпад R17 v1.0.97 / официальной версии 0.15.1

<a id="r17-v1097--official-0151-gamepad"></a>
Бинарный файл моста R7 GameSir Xbox и назначение кнопок перенесены из R17. Официальный padd собран без изменений. Веб-страница формирует стандартный ввод Xbox evdev, а не собственные robot.move или автоматические последовательности hold / start / stop.

- Start: сначала HOME; затем переключение официальной политики с возвратом в HOME при отключении.
- Select: короткое нажатие с отпусканием снимает крутящий момент; удержание 2 секунды запускает официальную последовательность посадки / выключения.
- Левый / правый стики: скорость, поворот, положение головы или корпуса согласно официальному режиму и параметрам `[pad]`.
- Y: режим головы. B: режим корпуса. LT / RT: официальные звуки и действия клюва.
- Крестовина вниз: исходная модель посадки / вставания на 10000 итераций.
- Кнопки навыков без моделей отключены на странице; A, X, LB и RB не назначены в `[pad]`.

При появлении физического контроллера серверная часть уничтожает веб-устройство evdev и отбрасывает ожидающие кадры. Тайм-аут веб-ввода 600 ms также уничтожает его. Первое веб-нажатие ожидает подтверждения подключения через доступный только для чтения `pad.input`, чтобы официальный интервал обнаружения 500 ms не пропустил Start.

При передаче управления не синтезируется отпускание Select и не отправляются отдельные команды robot.stop / robot.enable. Обработку отключения / отпускания по-прежнему выполняет официальный padd. Полные определения кнопок / осей находятся в `packaging/webpad.py` и исходном `gamepad-r7/gamesir-xboxd.c`.
