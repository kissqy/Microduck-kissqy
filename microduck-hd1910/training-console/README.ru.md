# 🧠 Microduck Training Studio · R1.5.27

Независимая консоль с китайским интерфейсом для организации задач обучения, управления очередями, просмотра кривых награды и журналов, оценки физических симуляций и экспорта ONNX и полных пакетов моделей.

**Текущая конфигурация: официальный Microduck 0.15.1 · официальный корпус + Feetech HD1910 · 14 категорий действий и 35 конфигураций задач.**

## Скачивание и запуск

Полностью распакуйте ZIP-пакет запуска. На компьютере, открывающем консоль, нужен **Python 3.10 или новее**. В Windows после установки должна быть доступна команда `py` или `python`.

| Система | Запуск |
| --- | --- |
| Windows | Дважды нажмите `start-training.cmd`. |
| macOS / Linux | Выполните `bash start-training.command` в этом каталоге. |
| Прямой запуск Python | Выполните здесь `python3 training_console.py --open`. |

Откройте **http://127.0.0.1:8092** и оставьте терминал запуска работающим. Исходники используют те же точки входа.

Страница работает независимо; обучение и симуляция выполняются на выбранном хосте. Для реального обучения используются **Linux / WSL2 + NVIDIA GPU**, а зафиксированный движок и зависимости подготавливаются через страницу. ZERO нужен только для получения физической калибровки, а не для самого обучения.

<a id="第一次训练"></a>
<a id="first-training-run"></a>
## Первый запуск обучения

1. **Выберите хост выполнения.** В **训练位置** («Место обучения») выберите **本机 / WSL** («Локально / WSL») или **SSH 服务器** («SSH-сервер»). Локальный вариант использует имеющуюся среду Linux / WSL. Для удалённого укажите хост, пользователя, порт SSH, аутентификацию и рабочий каталог; при первом использовании нажмите **部署并准备环境** («Развернуть и подготовить среду»).
2. **Один раз подготовьте среду.** Первичная подготовка скачивает зафиксированный движок и зависимости. Следующие сеансы используют готовую среду и кеш обнаружения.
3. **Подготовьте калибровку.** Импортируйте файл или запись консоли либо используйте **从 ZERO 获取** («Получить с ZERO»). Проверьте данные робота и сборки, используемые в этом запуске обучения.
4. **Выберите задачу.** Выберите действие, местность и конфигурацию люфта; задайте число параллельных сред, фактических итераций обучения и имя запуска. Для продолжения или совместного обучения выберите контрольную точку или учителя.
5. **Добавьте в очередь.** Нажмите **＋ 加入队列** («Добавить в очередь»). Каждая запись сохраняет параметры и калибровку в момент добавления. Последующие изменения страницы не переписывают задачи очереди.
6. **Запустите.** Нажмите **开始训练 ▶** («Начать обучение»). Следите за графиками, журналами и состояниями; для остановки используйте **停止训练** («Остановить обучение»).
7. **Оцените.** После сохранения контрольной точки выберите её в **模型与验证** («Модели и проверка»), затем нажмите **查看所选策略** («Просмотреть выбранную политику»).
8. **Экспортируйте.** **导出 ONNX** («Экспорт ONNX») создаёт модель для развёртывания и полный пакет. Импортируйте только типы моделей, поддерживаемые Robot Console.

Сначала проверьте конфигурацию задачи по умолчанию, затем меняйте по одной переменной. Для новых задач по умолчанию P=5 и масштаб действий=1.0; см. [подробные правила](USER-GUIDE.ru.md#current-training-and-model-rules).

## Симуляция и файлы моделей

| Файл или операция | Назначение |
| --- | --- |
| Контрольная точка PT | Продолжение обучения, выбор учителя или оценка сохранённой политики. |
| ONNX | Инференс, соответствующая оценка в симуляции и развёртывание на роботе. |
| Полный ZIP модели | Модель и сведения об обучении / развёртывании для переноса и импорта; сохраняйте экспорт целиком. |
| 查看初始模型 («Просмотреть исходную модель») | Проверка модели робота и начального состояния этой задачи. |
| 查看所选策略 («Просмотреть выбранную политику») | Запуск выбранной контрольной точки или ONNX. |
| 自动查看新检查点（周期评估） («Автоматически просматривать новые контрольные точки / Периодическая оценка») | Обновление окна оценки по мере сохранения контрольных точек. |

Мониторинг показывает активный запуск обучения; симуляция оценивает выбранную сохранённую модель. Сравнивайте этапы обучения периодической оценкой или выбором контрольных точек вручную.

## Локальные и серверные задачи

- **Локально / WSL:** записи и модели сохраняются в выбранном локальном каталоге обучения; страница показывает путь результата. Закрытие страницы не останавливает обучение. Используйте «Остановить обучение».
- **SSH-сервер:** очереди, обучение, оценка и результаты находятся в рабочем каталоге сервера. Загружайте / скачивайте модели через страницу. Отключение SSH или закрытие настольной консоли оставляет серверное обучение и очереди работающими.
- **После перезагрузки сервера:** подключитесь снова и продолжите из сохранённой контрольной точки.
