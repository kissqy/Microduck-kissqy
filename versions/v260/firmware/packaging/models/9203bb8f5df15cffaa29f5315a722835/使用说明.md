# HD1910 自训模型 · 目标固件 0.15.1

这是独立强化学习装死模型，与现有脚本装死分开。0.15.1可推理该网络，但需另接5秒技能及结束后的起身交接。

- 原生接口核对：`0.15.1` / `1fa84386f07884e27866411bc1ba166977bced95`；路由 `skill_with_recovery_handoff`，支持范围 `manual_configuration_required`。
- 按随包 R148 接口审计，该版本的任务白名单不接收此任务；其他实机中控版本需核对其导入合同。 本包是自训模型，不是官方已经验证的成品权重；不自动写入机器人配置。
- HD1910导入合同：V8训练方法＋R1.5.27 BAM的组合须由运行端按真实来源接收。已审V172/V173对hd1910-v8只接受厂家81a441…，本包不伪装成旧源码模型，也不修改机器人固件。
- 独立装死ONNX需要从稳定站姿触发，零twist/head/body运行5秒，结束时仍躺着；随后必须交给已验证起身策略。现有脚本装死不会自动调用此模型。
- 0.15.1没有每技能独立的头腿滤波覆盖；本模型训练为直通，接入端需落实匹配映射并恢复其它策略设置。本包不生成会全局改写Walk滤波的片段。

- 训练来源任务：`Mjlab-PlayDead-Flat-MicroDuck`；官方训练提交：`b02fdea4902c2b93b7d34a83a6f05da4ececb7d3`。
- 本次评估/导出任务：`Mjlab-PlayDead-Flat-MicroDuck`；导出源码：`b02fdea4902c2b93b7d34a83a6f05da4ececb7d3`。原训练摩擦：`official`（fixed=固定摩擦；official=官方随机化）。
- 模型：`policy.onnx`；`checkpoint.pt` 用于续训，不能直接交给 robotd 推理。
- `manifest.json` 使用官方 schema 2；本 ZIP 是训练归档，不能当作固件升级包。
- deployment-profile.toml仅记录接入限制；自定义技能端落实deployment-contract.json的required_playdead_controller_settings。不自动写入全局滤波或覆盖现有脚本。
- 训练未加额外头腿EMA；头颈/腿部直通 1.0。 此项为原训练历史；实际推理以 deployment-profile.toml 的参数为准。仿真训练使用 BAM 舵机动态；ONNX 保存策略网络及启用时的观测归一化，执行器物理参数另存于训练配置和部署合同。滤波作用于 Home＋动作系数×原始输出之后的关节目标，不缩小最终角度；ONNX图不内嵌此滤波。
- 稳定站立后，以全零twist/head/body运行5秒，之后交给已验证起身策略。动作直通HOME＋scale×raw，不使用行走的0.5/0.7滤波。0.15.1没有每技能滤波覆盖，需要在接入端完成设置切换。
- 电压补偿、增益及增益倍率不是本次训练动作项的配置字段，导出不强制开启、关闭或改成1。它们沿用运行端已有配置；如原配置已经是关闭，本片段不会自动改为开启。BAM供电随机化和负载掉压原样记录在训练快照，不能当作已训练运行端电压动作补偿。
- `training-config.json` 保存配置来源 `training_run_readback`、环境、奖励、课程、专家BC、BAM、质量和齿隙等。优先使用原训练启动读回；历史记录缺失时明确标为按保存配方重建，不伪造原训练读回。
- 观测归一化状态：`embedded_in_onnx_once`；启用时由官方导出器封装在ONNX内，运行端不要重复归一化。
- 必须使用 HD1910/IMU 适配驱动和当前机械装配的标定。包内标定只作来源记录，不覆盖实机零点。
- 齿隙仿真：`{"enabled": false, "joint_count": 0, "ranges_rad": {}, "encoder_position": "motor", "motor_velocity": "motor-side for friction and back-EMF", "policy_joint_velocity": "motor"}`。被动齿隙关节不作为ONNX动作导出，实机使用真实编码器反馈。
- 行走老师与联合模型都放 walk 槽；只有联合模型包含相应的倒地恢复训练。起身老师不是另一套“原地保持”策略。
- 捡取、轮滑蹲下和旋转使用相位指令，周期取原训练快照，结束相位为0.7；坐站使用姿态标志。前滚翻和左右脚踢球使用官方一次动作窗口。仿真回合长度不等于固件触发窗口。
- 左脚踢球使用左脚任务独立训练的模型；运行端不会因为文件名是 left 就镜像右脚模型。
- 本包通过模型格式和有限输出检查，不代表已经通过你的机器人实机步态验证。

动作、观测顺序、实际 Home、BAM 参数及训练快照见 `deployment-contract.json`、`training-config.json` 和 `upstream-params/`。
