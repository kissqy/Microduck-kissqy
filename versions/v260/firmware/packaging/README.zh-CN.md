# Microduck Console Studio V260 / control.102

本版以 V259 / control.101 为基础，作为移除火烈鸟后的发布包。

已从随包系统移除火烈鸟模型、默认动作配置、中控模型入口、按键说明及模型导入适配。升级会移除已保存的火烈鸟动作与指向已退役模型的别名绑定，并清理指定的旧火烈鸟模型目录；其余用户模型、标定、参数和按键绑定按原策略保留。新版中控连接仍报告该动作的旧固件时，也不会将它提供给 AI。

请完整解压新版中控，并安装本版随包固件，才能完成 Zero 上的旧动作和模型清理。仅替换电脑中控不会修改卡里的旧配置。

保留其余 11 个 ONNX 模型、AI、实体及网页手柄、音色、摄像头、关机和 R10 开机热点逻辑。实体方向键 ↑ 长按 3 秒切换行走／滑轮保留；短按不再有可执行的火烈鸟模型。原生运动与手柄程序逻辑沿用 V259，robotd 仅同步实际版本标识。

验证包括：全新与旧配置升级、别名与孤立按键清理、重复安装、真实文件安装器清理旧模型并保留用户模型、旧固件 AI 清单过滤、其余模型与资源校验、配网完整入口和安装包一致性。具体结果随包记录；没有进行本轮实体动作或热点验收。

项目状态：完成火烈鸟撤下与 V260 发布包整理。Known-Good 沿用此前实机参考；下一步唯一主任务：参考卡升级验收，确认旧动作已移除，其余动作及开机热点行为保持。
