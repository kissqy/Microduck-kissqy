# Руководство по сборке R17 V167 / control.43

Консоль: `1.0.167`. Прошивка робота: `1fa8438-feetech-ft6-control.43`. Официальная базовая система: `0.15.1`.

**Обновление: исправлено дрожание корпуса.**

<a id="源码与成品"></a>

## Исходники и готовые загрузки

Этот каталог хранит исходники, конфигурацию, тесты, лицензии и ресурсы интерфейса. Полные ZIP-архивы консолей находятся в `release-assets/` репозитория. Отдельная прошивка остаётся в `console/updates/` для существующего установщика консоли.

Скомпилированные программы, разделяемые библиотеки ONNX и дубликаты бинарных файлов упакованных моделей восстанавливаются из проверенной прошивки, а не хранятся дважды. Перед сборкой или запуском зависящих от пакета тестов:

```bash
python3 prepare-V167.py
```

Скрипт проверяет зафиксированные SHA256 и восстанавливает нужные ресурсы. Git игнорирует созданные копии. `--check` только проверяет хеши архивов; `--download` скачивает отсутствующие зафиксированные архивы и проверяет их хеши.

ZIP V164 хранится в одном экземпляре как база воспроизводимой сборки по пути `../../release-assets/build-baselines/Microduck-Console-R17-V164.zip`. Упаковка и проверка используют этот путь.

## Сборка

Требования: Linux/WSL, Rust 1.99, целевая платформа AArch64 GNU, cargo-zigbuild 0.23.4, Zig 0.15.1, Python 3, pkg-config и файлы разработки libudev. Обычная сборка исходников описана в [BUILD.en.md](../docs/BUILD.ru.md). Полное воспроизведение выпуска дополнительно требует ONNX Runtime 1.28.0 на хосте, QEMU и пользовательскую среду ARM64.

```bash
export ORT_DYLIB_PATH=/absolute/path/to/host/libonnxruntime.so.1.28.0
export QEMU_AARCH64=/absolute/path/to/qemu-aarch64
export ARM64_RUNTIME_PREFIX=/absolute/path/to/arm64-userland
bash build-V167.sh
```

Скрипт восстанавливает ресурсы, проверяет исходники, запускает исходные тесты выпуска, собирает robotd, проверяет комплектные модели и создаёт полный установщик V167 на основе исходной базы V164. Созданные ресурсы и результаты сборки не коммитятся.

## Записи

`verification/v167/` содержит прежние записи компиляции: 237 тестов Rust, 18 тестов Python и десять загрузок моделей с первым инференсом на ARM64/QEMU. Это исторические результаты выпуска, а не тесты, повторно запущенные при очистке каталогов. При очистке сравниваются исходники, архивы выпуска и байты восстановленных ресурсов без пересборки прошивки и работы с физическим роботом.
