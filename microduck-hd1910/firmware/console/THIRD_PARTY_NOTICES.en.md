## Development test dependencies

DOM tests use jsdom 26.1.0; browser regressions target Playwright. Neither is bundled or required to run the console. Preserve upstream licenses when installing development dependencies.

ONNX CPU tests use ONNX / ONNX Runtime / NumPy and generate tiny mathematical models in temporary directories, deleting them afterwards; they are not robot training weights. Browser tests use explicit simulated-state fixtures to check page / control requests, not GPU physics acceptance.

No robot keys, SSH known_hosts, private configuration, or user-camera imagery are bundled.

## Official chirp variants

`audio/chirp/chirp_a.wav` through `chirp_l.wav` are generated with the sounds 0.10.0 synthesizer from official 590 b 986, seed 590986, variants 0–11; 48 kHz, 16-bit, mono. They provide a manual chirp fallback when ZERO lacks the sound library; existing libraries take priority. Source / recipes follow official Apache-2.0; see `licenses/MICRODUCK-APACHE-2.0.txt`.
