# R1.5.16 本机 WSL 的 SSH 测试

现有本机训练通信方式：浏览器通过HTTP访问Windows中控 `127.0.0.1:8092`，中控调用 `wsl.exe --distribution 发行版 --exec python3`，通过进程标准输入/输出的JSON通道传递命令、日志和状态。训练任务在WSL独立后台进程运行，监控读取日志及状态。关闭中控后训练继续，WSL关机或系统重启会中断训练。

新的按钮用于验证SSH远程服务器通道。它通过 `wsl.exe` 一次性准备测试SSH，然后Windows OpenSSH连接 `127.0.0.1` 的专用端口，上传同版后端，通过SSH隧道读取其HTTP API和仿真画面。通过后可以切换到首尔服务器复用这一条通道。

## 使用

1. 关闭旧中控窗口，解压并启动本版完整包。原WSL后台训练继续；不要关闭或重启WSL。
2. 顶部填写实际WSL发行版名称，例如Ubuntu或Ubuntu-24.04，点击“本机 WSL 测试”。名称应与现有执行环境一致；可用Windows终端 `wsl -l -q` 查看。
3. 本入口只在Windows中控可用，需要已有WSL、Python3、Windows OpenSSH客户端、git。若WSL缺少sshd，将自动通过apt安装openssh-server，不安装或重建WSL。
4. 自动创建测试专用客户端密钥、WSL主机密钥、授权文件、SSH配置和回环端口；不改原用户的常规authorized_keys和sshd_config。客户端主机公钥通过所选WSL本地执行通道获取并存入专用known_hosts，SSH严格校验。
5. 测试后端保存在 `~/microduck-training-ssh-wsl-test`，使用独立运行记录和队列。它只检查已有固定版本训练环境，不自动切换源码或同步已有训练虚拟环境，不自动开始GPU训练。首次测试后需等待环境检查结果；缺少环境时看实际日志处理。
6. 已保存的外部服务器连接自动备份，可点击“返回服务器连接”恢复，然后连接首尔服务器。不会自动连接或启动服务器训练。
7. 选择“本机 / WSL”可以回到原本地训练记录和队列。SSH测试后端中的任务不会复制到本地队列，已运行任务也不会自动迁移。

现有动作倍率、滤波、P、物理配方和冻结源码没有改变。测试中控首次初始化配方快照，后续不覆盖；已有WSL运行训练保持原配置。

## 连接寿命

断开SSH只关闭Windows连接，测试后端继续运行。WSL退出、`wsl --shutdown` 或Windows关机会终止WSL中的服务和训练；保持WSL运行，勿在训练期间重启。WSL自动退出行为与Windows/WSL设置有关，建议保持已有WSL终端运行。

如果Windows不能访问测试回环端口，日志会提示检查localhostForwarding；入口不会为此重启WSL或重配网络。Windows侧端口被占用、WSL SSH进程异常、缺失OpenSSH、Python或网络下载失败均显示实际错误；失败时保持SSH目标，阻止意外在本机启动新训练。

## 验证范围

CPU/API测试覆盖同一SSH部署路径、外部连接备份恢复、失败不回退、测试密钥保留和手动换服务器清除测试元数据、带空格的专用known_hosts、Windows/WSL命令参数及主机密钥获取。系统OpenSSH协议集成覆盖部署、接口转发、模型合同保持、等待队列、重连复用后台、画面端口转发和关闭中控后服务继续。

当前验证环境为Linux，未实际连接用户Windows中的WSL，未启动GPU训练；真实WSL端口转发和训练环境检查需在用户Windows点击按钮执行。

WSL通信依据：[Microsoft WSL网络](https://learn.microsoft.com/windows/wsl/networking) · [WSL基本命令](https://learn.microsoft.com/windows/wsl/basic-commands)。

## GPU状态提示修复

SSH非交互会话的PATH可能缺少WSL专用工具目录，已增加 `/usr/lib/wsl/lib/nvidia-smi` 回退，与原训练worker一致。找不到状态工具、执行失败、超时均只表示状态查询结果，不冒充CUDA训练验证。CUDA实际可用性仍由训练环境读回决定。

本修正保持服务版本R1.5.16，使用修正版重启Windows中控并点击“连接 / 重连”即可更新连接处GPU信息，复用已有后台，不需重新部署或重启WSL。

训练模型导出：选择相应保存的PT → 导出ONNX → 完成后在训练成果中点击下载模型包。服务器端执行导出，通过SSH将含policy.onnx、checkpoint.pt及训练/部署合同的ZIP传回本机。
