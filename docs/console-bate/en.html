Workspaces

Four modes, one clear workflow.

Connect to ZERO by SSH, then select the workspace for the operation you need.

01 / TEST

Hardware tests

Inspect IMU orientation, microphone input and speaker sound. Wiring references are available on the test page.

02 / NUMBER

Servo numbering

Scan IDs 1–250, inspect actual positions, save joint IDs and perform single-servo midpoint calibration.

03 / CALIBRATE

Joint calibration

Check direction, zero and limits in a dedicated workspace with a larger 3D view. Hardware faults identify the affected device.

04 / MOTION

Robot motion

Gamepad hints, motion controls, joint feedback, curves, camera and ToF, with existing Chinese AI in a dedicated column.

HAT / Servo ID

Number servos through the HAT.

  1. Connect the hardware and SSH

    Follow the test-page wiring reference, supply the HAT and servos, start the desktop console and connect to ZERO.

  2. Connect one unnumbered servo at a time

    Servos with the same or unknown ID must be numbered individually. Verified distinct IDs can be chained.

  3. Scan, select and save

    Enter Servo numbering, scan IDs 1–250, check the detected servo and choose its target joint ID. Follow the UI for an occupied-ID swap.

  4. Check the full chain, then calibrate

    After all individual IDs are confirmed, reconnect the chain and scan again. Recalibrate any joint whose midpoint was changed.

What's new

What changed in this release.

  • Missing hardware no longer blocks recovery. Missing IMU or one or more servos releases the current initialization task, so Test and Number modes remain accessible.
  • Readable diagnostics. Calibration and Motion show specific IDs, Chinese explanations and key original errors. Full details remain in system logs; selecting a service mode does not imply hardware readiness.
  • Responsive workspace feedback. Scan, ID and midpoint results update in place; ordinary tab switches do not force a reload. SSH connectivity and robot service state are shown separately.
  • More focused controls. In-page error dialogs, illustrated controller hints, visible firmware/power controls and a dedicated AI column. Existing voice, role, vision and action features are retained.
  • Package cleanup. Historical verification archives, repeated notes and obsolete images have been removed while current runtime files and version-specific verification source are retained.

Get started

Run the console.
