# R1.5.15 SSH 远程训练

在训练中控顶部选择“SSH 服务器”。首尔服务器与其他地区使用相同流程，SSH延迟主要影响页面响应和文件传输。

## 首次连接

1. 解压本版完整包。关闭旧中控启动窗口，运行本版 `start-training.cmd` 或 `start-training.command`；这次更新包含后端代码，不能只覆盖网页静态文件。
2. 服务器需要 Linux、Python 3.10+、git、python3-venv，以及已分配的 NVIDIA GPU 和正常驱动。首次环境准备还需能下载 Python 包和固定版本 GitHub 训练源码。
3. 当前R1.5.16已支持密码登录，在服务器区选择登录方式并输入密码即可。首次使用会自动在中控数据目录安装密码SSH组件，需要本机Python有pip和软件下载网络；只准备一次。密钥模式继续使用系统OpenSSH客户端。
4. 选择“SSH 服务器”，填写 IP/主机名、用户名、SSH端口和可选的本机密钥路径。工作目录默认 `~/microduck-training-ssh`。
5. 密码模式首次连接时页面显示服务器SSH指纹，核对后点击“确认指纹并继续”。密钥模式可以在本机终端运行页面SSH命令，核对指纹并确认免密登录，加密密钥需先加入ssh-agent。
6. 点击“部署并准备环境”。中控上传同一版训练后端，创建独立目录，必要时在独立Python虚拟环境中安装uv，然后启动原有固定提交的源码/依赖准备流程。可在运行记录、实时日志里查看安装结果。
7. 环境就绪后，按原流程选择训练参数、加入队列、开始训练。

再次使用已经部署的服务器，点击“连接 / 重连”。打开页面或重连本身不添加训练任务。首次部署会准备训练环境，不启动GPU训练。

## 参数、老师和模型

- 远程训练使用本版原有训练入口、固定源码、动作倍率、头腿滤波、舵机P、物理参数、课程和导出流程。服务器不会因为所在地区改变这些配置。
- 首次部署把本机的机器人物理配方和标定快照初始化到新服务器目录。该目录已有配方时保留服务器配方，不重复覆盖。
- 普通训练参数仍在本次训练参数区编辑；加入队列时冻结。先选择服务器，再加入服务器队列。
- 本机老师或续训检查点通过“上传老师 / 续训模型ZIP”上传原中控导出的完整模型包，最多30MB。上传后在相应老师选择框或续训来源中选择它。
- 接收端核对任务、动作倍率、滤波、P、接口和ONNX哈希，保留原源码来源和原始包。旧包把倍率放在 `policy_parameters` 中时，读取其中的真实训练倍率。
- 旧包若缺少原训练并行数，仍可作老师；续训需要重新从原中控导出包含原训练配置快照的模型包。缺失数据不会被默认为4096来开放续训。
- 上传入口支持当前官方0.15.1训练源的独立动作模型。联合模型续训依赖其原来两位老师，请在原训练服务器续训。
- 联合训练仍使用现有机器人物理配置和动作合同匹配规则。这次SSH功能没有增加不同倍率老师的自动转换，也没有修改联合算法。
- 服务器训练的模型在原来的导出/下载按钮下载到本机。
- “从ZERO获取标定”仍从本机SSH读取机器人标定，再发送给训练服务器。

## 断线、关闭和重启

服务器训练服务独立运行，队列、训练记录和模型在服务器保存。关闭浏览器、关闭本机中控或断开SSH只关闭本机连接；服务器当前训练和后续队列继续。

重新打开本机中控后，保存的SSH目标保持选中，但不会自动连接或改成本机执行。点击“连接 / 重连”接回同一个服务器服务和已有队列。连接失败时远程训练提交被阻止。

明确点击“停止训练”才停止该服务器当前训练及后续队列。切换到“本机 / WSL”显示本机记录，服务器任务继续独立执行。

服务器断电或重启会中断GPU进程。重连后检查真实任务状态，从保存的PT另外加入续训任务。不要把断电与单纯SSH断线混为一谈。

服务器HTTP服务和本机隧道均只监听回环地址，主端口及仿真WebSocket通过SSH转发；不需要对公网开放训练网页端口。若服务器禁用了SSH端口转发，需由服务器管理员启用后使用。

## 本版验证

- 新增远程功能10项CPU/API测试通过：连接字段、认证失败不回退、目标持久化、服务器环境准备、模型合同保留、旧导出记录和续训门禁、请求凭据和画面转发。
- 使用真实系统OpenSSH客户端和隔离的SSH协议测试服务，验证上传/启动、API请求、PT上传、等待队列、断线重连同一后台服务、画面端口转发和关闭本机后服务器服务继续。该验证未启动GPU训练。
- 浏览器验证服务器选择、连接保存、端口、失败状态、切回本机和没有自动启动训练；原队列浏览器流程通过。
- 实际导入既有起身7000模型包，读取并保留0.7、头0.5/腿0.7和模型合同中的P5。此包缺少原并行数，作为老师可用，续训门禁保留。
- 原官方配置、队列、后台训练、P输入和滤波CPU回归通过。首尔服务器的实际GPU安装与长训尚未执行，需要填入其连接信息后验证。

实现依据：[OpenSSH配置手册](https://man.openbsd.org/ssh_config)；后台分离与部署流程为本中控实现。
