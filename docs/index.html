连接和数据能力

实际数据能力
原版：实测/目标角度、重力、运动意图、里程计、健康、总线电压、最高/平均温度、ToF。
舵机服务：15 颗舵机反馈与 IMU 姿态；运动循环运行时自动接入通信数据；未启动循环时可手动检测。
台架模式：逐颗电压、PWM、硬件错误、扭矩开关、PID、限值、零位偏移等；必须先停止 robotd，支撑好机器人。不写任何寄存器。
“负载”不是力传感器测量；界面仅报告可核实的电流及其限值占比。供电若已降压，官方电池百分比不适用。
