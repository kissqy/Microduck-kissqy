# Microduck Training Studio R1.5.17

本版修复**倒地起身老师的 PT / ONNX 评估课程不一致**：两种评估从训练最终课程开始，普通查看仍使用模型原地形。选择倒地老师后新增 **翻身检查**，在平地从完全背朝地、左侧躺、右侧躺或趴地开始，分别记录起身结果；也可切换到训练最终混合观察。自动重置不会计成起身成功。普通与专项仿真还可 **记录当前姿态**，把实际卡住时的关节、命令和接触诊断保存到完整日志。

使用方法、判定范围和验证记录见 [R1.5.17 翻身检查](docs/R1.5.17-recovery-evaluation.zh-CN.md)。基于 11000 轮模型的补课建议见 [翻身续训方案](docs/StandUp-11000-rollover-plan.zh-CN.md)。本包完成评估修复，补课方案尚未写入训练配方，也不会自动开始续训。

请运行完整本版启动脚本；只替换网页不能更新评估后端。SSH 服务器也需要部署同版后端，更新时遵循现有后台版本检查。原模型、训练记录和训练环境缓存沿用。

## 沿用的 R1.5.16 功能

本次修复 **安装成功后仍提示首次安装、无法开始训练**：完成安装与CUDA检查后，保存当前训练机器的就绪状态和检查缓存，不再清掉成功结果。已有服务器已完成下载但被旧提示挡住时，直接在页面下方“执行环境”点击“首次检查本机”（新版名称“首次检查训练机器”），无需重新安装；失败的队列项点击“重新训练”后再开始。[就绪状态修复说明](docs/R1.5.16-setup-ready.zh-CN.md)。

本修正版将服务器准备合并到 **部署并准备环境**：自动检查并补齐缺少的Python、对应venv/ensurepip、git、证书和必要系统库，自动准备uv，再继续安装固定版本训练环境。root账号直接执行；密码登录的sudo账号使用本次SSH密码，不需要另开终端逐个补包。已有uv（包括`~/.cargo/bin/uv`）及已就绪训练环境优先复用。[一次部署说明](docs/R1.5.16-oneclick-deploy.zh-CN.md)。

本版已补上 **SSH密码登录**：在训练服务器区选择“密码登录”，填写账号密码即可部署、重连、上传和下载。首次使用会自动准备密码SSH组件；首次主机指纹确认后继续。密码仅保留于本次中控运行，不写入连接配置；原密钥和WSL测试继续可用。[密码SSH使用说明](docs/R1.5.16-password-ssh.zh-CN.md)。

本包已修复WSL经SSH连接时找不到nvidia-smi的提示：支持WSL专用路径，保留现有驱动和训练配置。使用修正版启动本机中控后点击“连接 / 重连”即可刷新GPU信息，无需重启WSL后台。

本次增加 **本机 WSL 的 SSH 测试入口**：现有本机WSL训练保留 `wsl.exe` 通道；用独立测试目录验证首尔服务器将使用的SSH连接、后端部署和状态读取，支持恢复已保存的服务器连接。[本机WSL测试说明](docs/R1.5.16-wsl-ssh-test.zh-CN.md) · [SSH远程训练说明](docs/R1.5.15-ssh-training.zh-CN.md)。

沿用 R1.5.14 的 **舵机P / Servo P** 试训输入，默认3，可改回5。理论换算值2.69不能直接写入飞特整数寄存器；训练、仿真、续训和导出使用各自保存的实际P。旧模型不会套用页面的新P。[试训与输出限制说明](docs/R1.5.14-servo-p-trial.zh-CN.md)。

训练统一为 **选择参数 → 加入队列 → 开始训练**，单个任务也使用队列。绿色“加入队列”位于参数标题旁，开始/停止位于队列标题栏。队列标题显示实际正在训练的方案；编辑下一项参数不会改变当前训练显示。接触面、显存缓冲和地形组成直接显示在“本次训练参数”，可以对照官方默认值、下一次加入的值与当前运行配置。目标硬件仍为官方骨架＋HD1910；未改标定、物理默认值、动作系数、滤波、课程或冻结源码。
## 晚上连续训练

1. 选择动作，设置并行数、轮数、动作系数、滤波等，点击 **加入队列**。重复添加其他任务。添加只是排队，不会立即训练或执行环境检查。
2. 队列每项固定添加时的训练参数、机器人参数和标定。之后修改页面只影响下一次添加。可在等待任务间上移、下移或移除；依赖某个老师的联合任务必须排在老师后面。
3. **行走老师 → 起身老师 → 联合训练** 可以一次排好：先添加两位老师，再选择联合任务，在老师选择框选“队列老师”。两位老师需至少保存一份PT、使用一致的动作系数/滤波/策略网络和机器人物理参数。完成后联合任务自动取各自最新PT；队列不会判断老师是否已经学会走路或起身。
4. 点击 **开始训练**，后端逐个启动训练。上一任务退出并释放训练进程后才启动下一任务。单独训练已在运行时，队列等待它结束；不会终止它。中控曲线继续使用当前训练的真实日志。
5. **停止训练** 同时停止当前训练和队列后续执行；未开始的任务保留，再点“开始训练”继续下一项。停止/失败的任务只有点击“重新训练”才按原快照重新排队，不会自动重训。失败默认停止后续，也可选择跳过失败继续。需要按PT续训时选择原PT，另加入一项。
6. 本机训练可关闭网页，**保持启动窗口、电脑和WSL运行**。关闭启动窗口后，当前后台训练继续，后续任务在重新打开中控后接着执行。电脑重启或WSL退出不能保持GPU进程；队列不会把丢失的训练当成完成，也不会静默重训。

远程训练的队列和模型保存在服务器。SSH断开或关闭本机启动窗口后，服务器上的当前训练与后续队列继续执行；服务器关机/重启后需重连并从已保存PT续训，不会把中断任务自动当成完成。

队列最多100项，本机模式独立保存到本机配置目录 `training-queue.json`。刷新和重新打开不会清空；“清理已结束记录”不删除模型，尚被后续联合任务引用的老师记录保留。浏览器添加请求重试去重；恢复时按队列项和尝试编号找原训练记录，避免重复启动。同一中控队列顺序执行，不协调另一份中控或手动终端启动的GPU任务。

## 使用

Windows运行 `start-training.cmd`，Linux运行 `start-training.command`。本版新增后端功能，必须解压完整包并运行本版启动脚本，不能仅替换 `training/static`。若旧中控仍占用8092端口，先关闭旧启动窗口，再运行本版；已有同一电脑的训练记录、冻结源码和环境缓存继续使用。已有后台训练按其保存记录重新接回。

远程训练：页面顶部选择 **SSH 服务器**，填写 IP、用户名、端口，选择密码或密钥登录，再点击 **部署并准备环境**。密码登录填写SSH账号密码；密钥登录使用已有免密密钥。环境就绪后使用原来的 **加入队列 → 开始训练**。已部署服务器以后点击 **连接 / 重连** 即可。首尔与其他地区使用相同流程。

1. 在“训练动作 / Action”选择要训练的动作。
2. 同一动作只显示一次，用旁边的“训练地形”和“舵机齿隙”选择对应的原生配方。
3. 调整动作系数、滤波、并行数和轮数，先加入队列，再开始训练。切换任何选择都不执行环境检查。
4. 联合训练选择行走、倒地起身两位老师。普通老师可用于齿隙学生；老师原来源保持不变，迁移差异写入日志。老师与学生的动作系数、滤波和主动关节/机器人合同仍需匹配。
5. 用保存的PT进入仿真、续训或导出。仿真和导出沿用这个模型保存的物理配置，不套用页面后来选择的配置。

## 齿隙与动作处理

官方Backlash模型给14个主动关节各增加一个被动串联齿隙关节，默认±1°（总间隙2°）。HD1910执行器保留官方反馈：位置环读取电机角＋齿隙角，策略读取输出侧角度与角速度；BAM摩擦、反电动势仍读取电机侧角速度。被动关节不作为动作输出，模型仍为61维输入、14维输出。此默认值来自官方仿真，不代表已经测得本机各关节间隙。

新建行走老师、起身老师、联合训练默认动作系数0.9，头颈/腿部目标滤波0.5/0.7，均可以选择；其它动作系数默认1.0；坐站按固件运行分支固定1.0，避免训练出不能按原系数部署的坐站模型。这是本机训练实验设置。官方基础训练配置的动作系数仍为1.0、无额外EMA，没有将它冒充已使用这些参数的官方原训练模型。

动作处理为 `Home + 动作系数 × 原始策略输出`，然后每50Hz控制周期更新一次头腿目标滤波。ONNX保留原始策略输出；部署按包内 `deployment-profile.toml` 和模型合同落实一次动作系数映射与一次滤波，不重复叠加。导出不强制覆盖运行端的电压补偿、增益及增益倍率；这些运行设置与训练中的供电随机化分开记录。

## 保留与清理

旧HD1910/V2引擎和旧原地站立入口不出现在新训练列表。旧粗糙地形坐站、捡取入口移出新训练列表；未部署的Spin、Swizzle、RollerSlope、RollerStandUp实验入口没有加入。旧模型文件不删除，受支持的历史模型继续按原配置仿真和导出。

保存从1000实际轮起、每1000实际轮一次，最近10次训练记录规则不变。课程和默认预算继续按4096环境×24步的采样基准换算：2048乘2、1024乘4。源码默认轮数是预算上限，不是保证收敛或必须训满的轮数。

本版不写机器人固件或舵机寄存器。实际速度下发0、加速度不写寄存器41的约定不变。

## 接触面与物理参数

在“本次训练参数”的“接触面与物理参数”中查看足底接触摩擦、接触维度、接触求解软硬、nconmax/njmax缓冲、传感器匹配上限、凸碰撞迭代、物理步长、BAM摩擦随机倍率、转子惯量倍率、编码器误差和粗糙地形组成。支持修改的字段沿用现有任务覆盖机制，编辑立即同步；不可覆盖的模型继承项只展示。“运行配置”来自当前训练的启动读回；脚掌solref/solimp来自Entity编译读回，不是随机化后各鸭子实时摩擦值。未采集的历史记录明确显示未采集。

默认足底摩擦随机范围0.7～1.3；BAM摩擦倍率0.9～1.1，二者作用不同。行走老师的接触容量200，倒地起身老师35，按实际选中的官方配方显示，不自动更改。并行环境支持1～8192范围内的整数，包括3072；3072的默认预算与时间课程按4096/3072换算，整数边界按采样量取整。
