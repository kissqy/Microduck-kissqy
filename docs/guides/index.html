Microduck 飞特版从零复刻教程：材料清单、3D 打印、刷机、标定与训练

Microduck-kissqy 是 kissqy 基于 Pollen Robotics Microduck 0.15.1、已完成实机复刻的个人项目，面向 Radxa ZERO 3W + 15 个飞特 HD1910 舵机 + 本仓库 HAT / IMU。这里提供系统镜像、中文机器人中控、独立强化学习训练中控、自制电路板工程，以及全套打印件和摆盘。

当前稳定公开版本：机器人中控 R17 V167 / 固件 control.43 / 训练中控 R1.5.27。 本指南更新于 2026-10-23。版本及验证依据见发布基线。源码可获取；作者原创部分采用个人非商业许可，官方和第三方部分保留各自许可，见分项许可。

1. 准备材料与工具

先看鸭子采购总清单，分别准备鸭子本体、PCB 与工具。参考硬件是 ZERO 3W、15 个 HD1910、摄像头、ToF、扬声器、电池、HAT 与独立躯干 IMU。价格是历史订单参考，预算范围和未计入项目以采购表说明为准。

焊接、回流和烧录工具见工具清单。使用其他主控或舵机时，不要默认当前镜像和结构已经适配。

2. 打印零件并装配机械结构

下载全套打印件 · 缝合怪版：36 个 STL、1 个 3MF 项目、5 盘参考摆盘。根据实际打印机与耗材调整配置，TPU 部件使用对应材料配置。

电池仓有 HUB 组合版和官方式加厚卡扣版；IMU 安装位适配本仓库 IMU。2026-10-21 版增加腿部支撑斜面、去除腿外壳外侧沉孔，并整合无需拆舵机即可换装的脚掌与滑轮结构。滑轮使用 623ZZ 轴承。

本页是装配流程导航，零件说明见打印件页；不把文件数量当成实际装配数量。

3. 准备 HAT、IMU 与供电

HAT / IMU 硬件页提供工程、采购表和两种接口版本。制作过程分别见HAT 制作记录和IMU 制作记录及视频。

自制 IMU 需要单独烧录 STM32 FT6 固件。 给 ZERO 刷系统镜像或升级机器人服务不会烧录 IMU；接线、固件下载与步骤统一见IMU 烧录指南。

按装机注意事项配置 5 GHz Wi-Fi，并在总进电口并联 1000 µF 缓冲电容；电容极性、耐压和安装位置以该页说明为准。

4. 刷写系统镜像并连接中文中控

  1. 在系统镜像 R1 页面下载镜像，用 Armbian Imager 将压缩镜像直接刷入 TF 卡。
  2. ZERO 首次启动后，连接 Microduck-kissqy 热点，按提示配置家庭 Wi-Fi 和新的登录密码；未自动弹出页面时访问 http://10.42.0.1:8088。
  3. 从下载区取得机器人中控 V167，完整解压后运行 start.cmd；macOS 使用 start.command。
  4. 填入本机 ZERO 的 SSH 地址和登录信息。R1 镜像预装 control.40；通过 V167 中控安装随包固件，更新到 control.43。

软件包安装、日志与按键说明见V167 使用指南。网页在线演示使用模拟数据，实际连接需要本地运行中控。

5. 标定自己的机器人，再进行运动

逐一核对 15 个关节的零位、方向、限位，以及 IMU 安装姿态。参考样机的标定不能直接替代你的机械装配标定。

先检查中控的关节与姿态反馈，再按使用指南完成 HOME、保持和行走。实体手柄的模式切换、轮滑动作及条件，以V167 按键说明为准。遇到异常先确认发生在哪一环，见标定与运行问题。

6. 训练自己的动作并部署到实机

普通使用可以直接使用发布包里的模型，训练中控按需安装。训练中控 R1.5.27 指南包含环境准备、训练队列、奖励曲线、仿真评估和模型导出，公开版本提供 14 类动作、35 种任务配方。

训练流程是：准备环境 → 选择任务与参数 → 加入队列并开始 → 仿真评估 → 导出模型 → 核对固件和策略合同后进行实机验证。训练中控和机器人中控是两个独立工具；仿真成功不等于所有装配都能获得相同实机结果。

Microduck 飞特版复刻常见问题：刷机、标定、IMU、手柄断网与供电重启

适用：Microduck-kissqy，Radxa ZERO 3W、飞特 HD1910、机器人中控 V167 / control.43。作者：kissqy；更新：2026-10-23。从零复刻总指南。

Microduck 复刻需要多少钱？材料清单在哪里？

本仓库按实际订单整理了复刻材料清单与成本明细，分别列出本体、HAT、IMU 与工具。价格是历史采购记录，打印件、设备、耗材、手工时间及未列价项目的计价范围以采购页为准，已列材料合计不等于每个人的最终复刻总成本。

Microduck 复刻的 3D 打印 STL 和摆盘在哪里？

缝合怪打印件页提供全套 STL、5 盘 3MF、预览和校验值。按自己的打印机、材料以及电池仓与 IMU 适配情况使用。

Microduck 飞特 HD1910 版需要下载什么？

普通使用先下载系统镜像 R1 和机器人中控 V167。训练自己的动作时，再下载训练中控 R1.5.27。下载统一见首页下载区。

R1 镜像预装 control.40，安装 V167 随包固件后更新到 control.43；这两个版本标识分别对应镜像内容与当前稳定运行固件。

在线中控演示能连接我的鸭子吗？

不能。GitHub Pages 上的机器人中控和训练中控是模拟数据演示，用于预览界面。控制实机需要完整解压机器人中控并在本地启动，再填写 ZERO 的 SSH 地址与登录信息。见V167 使用说明。

刷了 ZERO 镜像，为什么 IMU 还需要烧录？

ZERO 系统和 IMU 上的 STM32 是不同设备。镜像与机器人服务安装在 ZERO，自制 IMU 需要单独烧录 FT6。下载、SWD 接线、烧录与通信检查统一见IMU FT6 指南。

接入无线手柄后，为什么 ZERO 断网或 SSH 超时？

作者实机遇到过 2.4 GHz Wi-Fi 与手柄无线通信干扰。按本项目配置，将 ZERO 连接到路由器的 5 GHz Wi-Fi，并确认实际频段，不只看网络名称。查询命令与说明见联网注意事项。

SSH 超时本身不能证明一定是无线干扰；仍需结合 ZERO 是否重启、网络是否保持连接和实际频段判断。

舵机大负载运动时，为什么 ZERO 重启？

作者实机经验是总进电口缺少缓冲电容时，大负载瞬态容易导致 ZERO 重启。本项目装机要求在总电源输入两端并联 1000 µF 电容，接线、耐压与极性见供电注意事项。若仍重启，继续检查电池、电源、线材、接头与负载压降，电容不能替代足够的供电能力。

舵机动作方向或姿势不对，可以直接复制作者标定吗？

不能直接照搬。每只机器人都要核对零位、方向、限位和 IMU 安装。先比较中控关节反馈、机械实际运动与标定，再启用模型；不要用增大力度来掩盖方向或机械装配错误。机器人中控指南是当前版本的操作依据。

HAT 和 IMU 有哪些接口版本？

仓库保留 EH2.5 原版和 AMP2.0 版。AMP2.0 版的舵机接口为飞特 AMP2.0，音频接口及新增 LED 见版本说明。工程和购买入口见硬件页，制作过程见 HAT / IMU。

换脚掌和滑轮一定要拆舵机吗？

当前缝合怪打印件包含方便换装的脚部结构，支持装滑轮时不拆舵机；滚轮轴承为 623ZZ，尺寸 3 × 10 × 4 mm。使用配套零件并核对摆盘材料，两种电池仓的 IMU 位适配本仓库 IMU。

训练需要连着 ZERO 吗？仿真成功就能上实机吗？

训练中控独立运行，训练本身不要求连接 ZERO；读取当前标定时才需要按指南连接或导入。仿真与实机存在装配、标定、动力学和供电差异，仿真结果不能替代实机验证。环境、任务、评估和模型导出见训练指南。

问题解决不了，反馈时需要什么？

在 Issues 写清：硬件与接口版本、机器人中控版本、实际固件标识、操作步骤、异常现象及日志或视频。先区分连接失败、服务启动失败、通信异常和运动异常，有助于复现。
