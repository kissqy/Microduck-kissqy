Workspaces

四个模式，按当前步骤操作。

先通过 SSH 连接 ZERO，再从左侧进入需要的工作台。测试和编号入口可用于处理缺设备或接线问题。

01 / TEST

IMU / HAT / HUB 测试

查看 IMU 姿态和麦克风电平，播放扬声器鸭叫。同页查看白底接线参考图，先确认基础硬件。

02 / NUMBER

舵机编号

手动扫描总线，查看实际位置与对应关节，保存目标编号。支持单颗中位校准和按提示交换关节编号。

03 / CALIBRATE

关节标定

按操作分列，保留较高的 3D 模型。核对每个关节的方向、零位与限位，缺设备时显示具体故障。

04 / MOTION

机器人运动

实物转绘手柄附操作说明，集中显示全关节反馈、曲线、摄像头和 ToF，中文 AI 独立一列。

HAT / Servo ID

用 HAT 给舵机编号，按这四步来。

  1. 接好 HAT，并连接 ZERO

    按测试页接线参考连接 ZERO、HAT 与舵机电源。在电脑端启动中控，通过 SSH 连接机器人。

  2. 未编号的舵机，一次只接一颗

    未编号或可能重号的舵机须逐颗连接，避免同 ID 冲突。已经确认编号不同的舵机可以串联。

  3. 扫描 → 选择舵机 → 保存目标编号

    进入“舵机编号”，手动扫描总线。核对实际位置和对应关节后保存；选择已占用编号时，按界面提示完成交换。

  4. 接回整链核对，再做关节标定

    全部逐颗编号完成后串联扫描核对。单颗中位校准把当前位置设为 2048，之后须重新标定该关节。

从 V260 到 V313 的累计更新

  • R3 启动布局 改用单分区 MBR，根分区从 16 MiB 处开始。制作时回读 Rockchip 引导程序，并将解压后的成品与原始镜像比对 SHA-256。
  • HAT 编号与关节标定 通过 HAT 扫描和改号、交换两个关节编号，或把单颗舵机当前位置设为中位 2048。标定页提供零位与 HOME 的 3D 参考。
  • 逐设备通信 每张设备卡片保留最近一次超时的采集编号和耗时（毫秒）。某颗舵机累计未回包超过 10 次，可将它移到读取队列末尾，顺序保存在机器人端。

从刷卡到连上中控

  1. 新卡刷入 R3

    用 Armbian Imager 选择 R3 的 .img.xz 文件，核对目标 TF 卡。写入会覆盖整卡，完成写入校验后再插卡上电。

  2. 手机配网

    R10 仅在开机时检查网络。优先连接已保存的 Wi-Fi，连不上才开启 Microduck-kissqy 热点（密码 12345678）。手机连接后打开 http://10.42.0.1:8088。运行中掉线不会自动开热点。

  3. 在电脑上打开 V313

    完整解压中控 ZIP。Windows 双击 start.cmd，macOS／Linux 运行 bash start.command。在 http://127.0.0.1:8090 填入 ZERO 的实际 IP 并连接，在「系统维护」核对固件。首次运动前核对本机标定，再执行 HOME → 保持 → 行走。
