# Самостоятельно обученная модель HD1910 · Целевая прошивка 0.15.1

<a id="hd1910-自训模型--目标固件-0151"></a>
<a id="hd1910-self-trained-model--target-firmware-0151"></a>
Официальный слот модели: `walk`.

- Исходная задача обучения: `Mjlab-VelStand-Rough-Backlash-MicroDuck`; официальный коммит обучения: `8d0db74916a4f833d1d9b95d6a1d7f4d13b9d5ec`.
- Задача оценки / экспорта: `Mjlab-VelStand-Rough-Backlash-MicroDuck`; исходник экспорта: `8d0db74916a4f833d1d9b95d6a1d7f4d13b9d5ec`. Исходное трение обучения: `official` (fixed=фиксированное трение; official=официальная рандомизация).
- Модель: `policy.onnx`; `checkpoint.pt` предназначен для продолжения обучения и не может напрямую передаваться robotd для инференса.
- `manifest.json` использует официальную схему 2. Этот ZIP — архив обучения, а не пакет обновления прошивки.
- `deployment-profile.toml` — официальный фрагмент `[policy]`. Объедините его с существующей рабочей конфигурацией; не заменяйте файл целиком.
- При обучении не использовалась дополнительная EMA головы / ног; голова / шея и ноги используют пропуск без фильтрации 1.0. Динамика сервоприводов BAM сохраняется в модели обучения. Фильтрация применяется к целям суставов после Home + масштаб действий × сырой выход, без уменьшения итогового угла. Этот фильтр не встроен в граф ONNX.
- Комплектный `manifest.json` фиксирует параметры, но не гарантирует их автоматическую загрузку средой выполнения. При развёртывании применяйте масштаб действий и фильтрацию головы / ног из `deployment-profile.toml`.
- Компенсация напряжения, усиления и множители усиления не являются полями конфигурации этого обучаемого действия. Экспорт не включает / выключает их принудительно и не устанавливает в 1; они сохраняют существующую рабочую конфигурацию. Этот фрагмент не включает отключённую настройку. Рандомизация питания BAM и падение напряжения под нагрузкой сохранены в снимке обучения и не подтверждают обучение рабочей компенсации действий по напряжению.
- `training-config.json` хранит происхождение конфигурации `training_run_readback`, среду, награды, программы обучения, экспертное BC, BAM, массы, люфт и другое. Приоритет имеет исходное считывание при старте обучения. Отсутствующие исторические записи явно помечаются как реконструкция из сохранённых конфигураций, а не выдаются за исходное считывание.
- Нормализация наблюдений: `embedded_in_onnx_once`; если она включена, официальный экспортёр встраивает её в ONNX. Не нормализуйте данные повторно при выполнении.
- Используйте драйвер адаптации HD1910/IMU и калибровку текущей физической сборки. Комплектная калибровка служит только сведениями о происхождении и не перезаписывает нули физических суставов.
- Симуляция люфта: `{"enabled": true, "joint_count": 14, "ranges_rad": {"passive_left_hip_yaw_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_left_hip_roll_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_left_hip_pitch_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_left_knee_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_left_ankle_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_neck_pitch_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_head_pitch_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_head_yaw_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_head_roll_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_right_hip_yaw_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_right_hip_roll_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_right_hip_pitch_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_right_knee_backlash": [-0.017453292519943295, 0.017453292519943295], "passive_right_ankle_backlash": [-0.017453292519943295, 0.017453292519943295]}, "encoder_position": "motor + passive backlash", "motor_velocity": "motor-side for friction and back-EMF", "policy_joint_velocity": "motor + passive backlash"}`. Пассивные суставы люфта не экспортируются как действия ONNX; робот использует фактическую обратную связь энкодеров.
- Учителя ходьбы и совместные модели используют слот walk; только совместная модель включает соответствующее обучение восстановлению после падения. Учитель восстановления не является отдельной политикой неподвижного удержания.
- Подбор использует фазовые команды; посадка / вставание — флаг позы. Кувырки вперёд и удары левой / правой ногой используют официальное окно однократного действия. Длительность эпизода симуляции не является окном запуска прошивки.
- Этот пакет прошёл проверки формата модели и конечности выходных значений; это не подтверждает пригодность физической походки на вашем роботе.

Порядок действий / наблюдений, фактический Home, параметры BAM и снимки обучения см. в `deployment-contract.json`, `training-config.json` и `upstream-params/`.
