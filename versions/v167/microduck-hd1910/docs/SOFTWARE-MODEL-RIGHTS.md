## “作者自训”具体表示什么

作者针对 HD1910 硬件开展训练、选型、部署参数适配和真机验证，这些工作应保留作者归属。当前可核对的模型、标识、来源文件及历史样本已单独整理为 [逐模型来源表](MODEL-PROVENANCE.md)。不要把软件代码、神经网络权重、机器人三维结构文件统称为同一种“模型”。

| 情况 | 本项目的处理方式 |
| --- | --- |
| 使用上游训练框架，独立初始化并训练新权重 | 可据实标注训练者及其原创贡献；分别确认框架、配置、训练素材与权重的许可 |
| 从已有检查点继续训练、微调，或使用教师策略蒸馏 | 保留基座／教师来源、许可和训练关系；新增训练贡献不替代上游权利 |
| 只改文件名、导出格式、推理倍率或滤波值 | 不据此声称新训练或完整原创；部署适配与权重训练应分开记载 |
| 训练记录没有说明初始化方式或教师来源 | 如实写“未记录”，不推定全部从零训练，也不据此否定作者已经完成的训练贡献 |
| 使用者自己训练的新模型 | 本软件许可不自动把使用者的输出模型归给本项目作者；按其实际创作、输入来源和适用许可判断 |

模型权重本身能否构成著作权法上的作品，需要结合具体独创性和事实判断；训练投入或适配某种舵机，不自动产生对全部数值、通用动作、算法或接口的排他权。本项目对作者依法享有且可单独许可的成果声明权利和许可条件，不保证每一项参数当然具有独立著作权。

**单脚独站实机演示是作者展示的训练成果。当前公开树中未定位到与演示一一对应、可核验的独站权重包和训练来源记录，因此不把它冒充为已包含在当前十模型发布包里的可下载模型。** 后续发布时再补充准确标识、哈希与来源。
