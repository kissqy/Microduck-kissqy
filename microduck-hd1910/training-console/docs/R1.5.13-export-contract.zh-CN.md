# R1.5.13 导出合同核对

本版修复导出时擅自覆盖运行参数，以及将重建配置误当作原训练配置的问题。冻结训练源码、BAM、机械参数、奖励、课程、训练默认值和页面布局未改。已有PT可以重新导出，无需因此重新训练。

## 已修复

| 项目 | 原处理 | 当前处理 |
| --- | --- | --- |
| 电压动作补偿 `voltage_adapt` | 导出固定写false，说明要求关闭 | 删除强制覆盖，沿用运行端配置；明确它不等于BAM供电随机化 |
| 动作增益倍率 | 捡取、前滚翻、踢球、坐站等导出时按分支固定写1 | 不推测训练中未记录的固件增益倍率，不修改运行端设置 |
| 观测归一化 | 合同固定声称ONNX内嵌归一化 | 按原训练actor的实际 `obs_normalization` 记录 |
| 原训练配置 | 导出时重建的环境可能省略老师BC，推扰/课程也可能属于评估配置 | 优先绑定原训练启动读回，完整保存环境、agent和机器人物理；旧记录缺失时明确标为重建 |
| 合同与manifest | 原manifest没有部署必需参数和运行参数来源说明 | 两者记录相同的动作/滤波参数、归一化、运行参数处理方式和训练快照哈希 |
| 模型归档 | 只有原params YAML和部分合同 | 增加 `training-config.json`，并在新导出和ZIP重打包时保留 |

## 保留并核对

- 动作系数读取原训练配置，不读取当前页面选值；0.7、0.9、1.0均原样导出。
- 头颈/腿部EMA读取实际动作项；开启时保持实际系数，未训练滤波的历史模型仍是1/1，不给旧权重冒加滤波。
- Home、关节顺序、控制频率、观测顺序、动作裁剪和历史长度按原训练核对；接口不一致只在导出时报出差异，不发起训练前检查。
- BAM参数、P值、执行器延迟、供电范围、负载掉压、摩擦随机化、转子惯量随机化、传感器噪声、足底接触、地形、质量及齿隙完整保存。仿真物理不是固件开关，不会因ONNX只含策略网络就被视为“关闭”。
- 联合训练的奖励、复位概率、课程和专家BC保存在原训练快照。导出只加载学生网络，不需要让固件运行PPO或BC训练算法。
- 当前机械装配的标定和训练来源标定分别记录；导出不把旧零点强制覆盖到重新装配的实机。
- 官方相位/姿态指令合同、动作槽和运行窗口保留原有规则。运行窗口不等于训练回合长度。

## 电压和增益的边界

训练中的 `vin_range` / `vin_drop_gain_range` / `vin_min` 模拟供电与负载掉压。当前训练动作项没有运行端的 `action_scale × nominal_voltage / measured_voltage` 补偿。不能把供电随机化解释为已经训练动态倍率补偿，也不能据此强制关闭补偿。

新版配置片段不写电压补偿或增益倍率，保持运行中控/固件已有配置。如果实机之前已经配置为关闭，重新导入本片段不会自动开启。是否采用官方补偿属于运行端设置；本次没有写ZERO或修改固件。

BAM实际 `kp_fw` 继续写入硬件合同，并保留参数文件内容。它不能在缺少飞特翻译层映射依据时直接转换成官方 `[policy].gain` 或某个增益倍率。

## 使用

解压新版中控，运行 `start-training.cmd`。这是后端导出修复，单独覆盖网页不会更新导出代码。原运行记录仍从现有本机数据目录读取；对其它已有PT在新版中控重新导出，即可得到新版合同和训练快照。旧ZIP不会被偷偷改写。

随本次交付另附14000轮/3072环境行走老师的合同修正版。其训练YAML确认动作系数0.7、EMA头0.5/腿0.7、粗糙地形与14关节齿隙。只更新归档说明与合同，ONNX和PT字节均保留；包内校验记录列出哈希。

历史验证报告中的“必须关闭电压补偿”以本版更正为准。
