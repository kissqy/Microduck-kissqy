Проверка Microduck Training Studio R1.5.20 — 2026-10-07

Охват: только реализация в исходниках и переносимые тесты.
Команды роботу, запись прошивки, реальное обучение и вычисление политики на GPU не выполнялись.

Охват переносимых тестов Python: пройдены 138 различных тестов.
- Существующая базовая регрессия: 111 тестов.
- Сценарии профиля старта из записи: 6 дополнительных тестов (с несколькими подслучаями недопустимых кадров).
- Проверки запроса/API/изоляции/журнала старта из записи: 8 дополнительных тестов.
- Математика/сброс/считывание/жизненный цикл выполнения старта из записи: 13 дополнительных тестов.
Базовые тесты + профиль + первые 7 случаев API выполнены одним набором из 124 тестов; итоговые 8 случаев API, 5 существующих случаев API целевых ограничений и 13 новых случаев выполнения прошли дополнительным набором из 26 тестов после последних изменений журнала/считывания.

Проверка синтаксиса JavaScript пройдена. Пройдены обе тестовые среды Node DOM/HTTP для UI целевых ограничений и восстановления, охватывающие стандартный запуск/старт из записи, ошибку отсутствующей позы, вывод исходного кадра и численного считывания, остановку и скачивание.
Это не проверка отрисовки реального браузера, 4K, CSS, Viser или WebGL.

Существующие тесты восстановления на реальных upstream-исходниках требуют закреплённых зависимостей симулятора; 5 таких тестов пропущены, поскольку зависимости здесь недоступны.
Torch/MuJoCo/mjlab/ONNX runtime и веса ONNX пользователя не устанавливались и не скачивались только ради этой проверки. Фактические результаты переката/подъёма неизвестны до запуска нового режима пользователем на существующей обучающей машине.

Предоставленная реальная запись успешно разобрана: первое включение StandUp использует непосредственно предшествующий почти неподвижный отсчёт; извлечены все 14 именованных суставов политики без рта, исходный хеш модели сохранён.
Чистая кватернионная проекция входной гравитации совпала с точностью 9e-9 по L2.
Это не свидетельство успешного физического прогона.

Изменения сохраняют исходное преобразование целевых значений и проверки равенства условий старта. Применение записанной позы сохраняет выбранные backlash/bias, повторно использует существующее геометрическое размещение на плоскости и не выполняет скрытых физических шагов. Несовпадение перед первым действием в позе энкодеров, гравитации корпуса, согласованности гравитации из qpos или нулевой скорости блокирует запуск. Нечисловые и бесконечные значения отмечаются как недопустимые и никогда не принимаются по допуску.

Этот режим запроса нельзя передать в обучение, очереди, экспорт, воспроизведение PT, обычный ONNX или операции кэшированной пробы. Исходная модель, рецепт, параметры и пользовательские записи остаются отдельно от этого пакета Public с исходниками.

Проверка пакета Public также охватывает CRC ZIP, манифест SHA256 для каждого поставляемого файла, исполняемый режим start-training.command и импорты из чисто распакованного пакета.
