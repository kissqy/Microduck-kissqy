R1 contains control.40; install V167's bundled firmware to reach control.43. For V260 features, use the separate [V260 directory](../v260/).

The original `microduck-hd1910/firmware/console/` and `release-assets/build-baselines/` structure is retained so the packaging paths remain valid. Treat this version directory as the original repository root when following its build instructions. Original source and runtime resources come from [a192f3b](https://github.com/kissqy/Microduck-kissqy/commit/a192f3ba54d1921383afbd790fa7d94ea859a3c4); source files, firmware and models are unchanged.

Source, ZIPs, firmware and build-baseline files retain their original contents; navigation in the archived installation guide is updated for its current location. This adds no compilation or robot acceptance claim. Existing V167 Known-Good records and component licenses remain applicable; see [licensing](microduck-hd1910/LICENSE). Historical source documentation is preserved; public setup guides are in the project's [current docs](https://github.com/kissqy/Microduck-kissqy/tree/main/docs).
