# 🖨️ Полный комплект деталей утки для печати · FrankenDuck

<a id="-鸭子全套打印件--缝合怪版"></a>
<a id="-complete-duck-printing-parts--frankenduck-edition"></a>
**Комплект объединяет улучшения нескольких участников сообщества и изменения kissqy, сделанные при сборке, эксплуатации и обслуживании реального робота. Поэтому он называется FrankenDuck («сборная утка»).** Изменений много, и по отдельности они не перечислены. Пакет содержит полный авторский набор деталей утки для печати и эталонную раскладку на столах.

**[⬇️ Скачать полный пакет (RAR, 14.54 MiB)](https://github.com/kissqy/Microduck-kissqy/raw/refs/heads/main/hardware/3d-print-frankenduck/Microduck-Print-FrankenDuck-20261015.rar)** · [SHA256](SHA256SUMS) · [Состав пакета](FILES.ru.md) · [Список покупок](../../DUCK-SHOPPING-LIST.ru.md) · [Главная](../../README.ru.md)

Опубликован **15 октября 2026 года**. В архиве **36 файлов STL и один проект 3MF с 5 столами**. Исходные имена и раскладки сохранены; число файлов не равно количеству деталей для сборки. Исходный архив предоставлен без редактирования моделей или проекта раскладки.

**Обновление 21 октября 2026 года:**

- **Добавлены скосы на опоры ног**, облегчающие установку стоп и уменьшающие вероятность разломить стопу усилием при сборке.
- **Убраны наружные цековки на обеих оболочках ног**, чтобы сохранить больше материала вокруг отверстий винтов и снизить риск разрушения при падении.
- **Интегрирована конструкция сменных стоп на основе официальных роликовых башмаков**, упрощающая смену стоп и роликовых узлов без снятия сервоприводов.

<a id="先看这几项"></a>
<a id="read-these-first"></a>
## Сначала прочитайте это

- **Комплект стоп позволяет установить ролики без снятия сервоприводов.** Это упрощает монтаж и обслуживание.
- **Выберите один из двух держателей аккумулятора.** Один зажимает плату HUB; второй следует официальной конструкции с утолщёнными защёлками.
- **Оба держателя имеют крепление IMU для самодельного IMU этого репозитория.** Для другого IMU адаптируйте крепление к форме, размерам и способу закрепления вашей платы.
- **Ролики используют подшипники 623ZZ: внутренний диаметр 3 mm × наружный диаметр 10 mm × ширина 4 mm.** [Товар из предоставленного заказа](https://item.taobao.com/item.htm?id=618009195719), продавец **EVT进口轴承**, точный вариант заказа **«623 内3外10厚4»**.

<a id="两种电池仓怎么选"></a>
<a id="choose-the-battery-holder"></a>
## Выбор держателя аккумулятора

Оба файла находятся в архиве в `3D打印缝合怪版/stl模型/躯体部分/`:

| Вариант | Имя файла | Применение |
| --- | --- | --- |
| **Держатель с зажимом HUB** | `电池仓_M2.5螺丝_HUB组合.stl` | Выбирайте, если держатель должен также зажимать плату HUB. Совмещённая с HUB конструкция на винтах M2.5; используйте по необходимости. |
| **Держатель официального типа с утолщёнными защёлками** | `电池仓_卡扣加厚.stl` | Держатель официального типа с утолщёнными участками защёлок; при желании импортируйте этот STL вместо держателя на столе. |

Оба подходят к [IMU этого репозитория](../README.ru.md). Подключение и прошивка описаны в [руководстве FT6](../IMU-FIRMWARE.ru.md).

<a id="怎么使用打印包"></a>
<a id="use-the-package"></a>
## Использование пакета

1. Скачайте и распакуйте RAR. **`缝合怪摆盘.3mf`** в корне — эталонный проект раскладки; `stl模型/` содержит отдельные модели по категориям.
2. Откройте 3MF как проект в Bambu Studio. Записанная конфигурация: **BambuStudio 02.08.02.61 / Bambu Lab P2S / сопло 0.4 mm / 0.20 mm Standard**. Настройте принтер, сопло и материалы под своё оборудование.
3. Выберите вариант держателя аккумулятора. Импортируйте отдельные STL, чтобы изменить раскладку, количество или повторно напечатать деталь.
4. **Стол 5 называется TPU; `TPU部分/` содержит две подошвы и шину.** Сохранённые пресеты материала проекта — PLA. Перед печатью этого стола выберите **профиль фактически используемого TPU**.

Настройки слайсинга жёстких деталей выбирайте по материалу, принтеру и требованиям сборки. Предоставленная раскладка сохраняет расположение автора; её настройки нужно адаптировать к целевому оборудованию.
