# Документация Microduck R17 V164 / control.40

<a id="microduck-r17-v164--control40-documentation"></a>
Актуальное описание пакета находится в [README R17](../README-R17.ru.md). Установка на этого робота и назначение кнопок физического геймпада описаны в [руководстве по консоли](../console/USER-GUIDE.ru.md).
[Руководство по прошивке](../packaging/README.ru.md) — основной источник перечня поставляемых моделей и калибровок;
[руководство по сборке](../../docs/BUILD.ru.md) определяет инструментарий ARM64 и область проверок.

Ниже приведены материалы об архитектуре исходных служб upstream и интерфейсах разработки.

[`faq.md`](faq.ru.md) — ещё одна отправная точка: вопросы по задачам разработчика, который создаёт что-то *для* робота, а не меняет самого робота. Например, как запустить слишком тяжёлую для платы модель, получить изображение камеры в своей программе или разобраться, почему Space не подключается.

Здесь же начинает **автор публикуемой модели**: [`policy-manifest.md`](policy-manifest.ru.md) задаёт контракт `manifest.json`, лежащего рядом с файлом microduck `.onnx`, и определяет каждое поле. Документы по проектированию объясняют решения и ссылаются на этот контракт.
