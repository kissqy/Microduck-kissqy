# Регрессионный тест отключения GameSir

Запускайте в Linux из корня исходников. Тест включает рабочие функции C обработки событий / ошибок и переподключения, использует реальные неблокирующие каналы и `poll()`, подменяя только обнаружение оборудования, `ioctl`, ошибки чтения и часы переподключения. Он не открывает реальное устройство input/uinput и не отправляет команды роботу.

```bash
cc -std=c11 -O2 -Wall -Wextra -Werror gamepad-r7/tests/test_gamesir_disconnect.c -o /tmp/test-gamesir-disconnect
/tmp/test-gamesir-disconnect
```

Покрытие:

- HUP вспомогательного источника удаляет и закрывает только вспомогательный fd; следующий poll ожидает, а не возвращает HUP непрерывно, и основной ввод продолжает передавать START, стик, оба направления триггера и SYN.
- HUP основного источника выходит в существующий внешний путь переподключения / очистки.
- Оба источника трактуют POLLERR/POLLNVAL, EOF, ENODEV, EBADF и EIO как постоянные ошибки; EAGAIN/EWOULDBLOCK/EINTR оставляют дескрипторы активными.
- Очистка закрывает вспомогательный дескриптор только один раз.
- Клавиши HOME/media потребительского устройства остаются вне карты кнопок Xbox.
- Отсутствующий вспомогательный узел проверяется не чаще раза в секунду; после возвращения он открывается и захватывается заново. При наличии вспомогательного узла поиск устройств не выполняется.

Идентификатор виртуального Xbox, обнаружение / масштабирование осей и назначения ввода остаются прежними. Потеря вспомогательного источника сохраняет основной виртуальный контроллер работающим. Полная потеря основного устройства по-прежнему пересоздаёт его через исходный внешний цикл. Тест подтверждает обработку ошибок / восстановления; он не заявляет об измеренном снижении температуры робота.
