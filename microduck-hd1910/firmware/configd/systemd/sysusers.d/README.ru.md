configd работает от root, поэтому отдельный пользователь ему не нужен; обоснование см. в configd.service. Ему нужна группа `robot`, которую уже создаёт updater/systemd/sysusers.d/robot.conf.

Этот файл намеренно отмечает отсутствие записи: если configd когда-либо перейдёт на непривилегированного пользователя (для чего нужен polkit в образе), его запись sysusers должна находиться здесь.
