# Прошивка Microduck control.43 и консоль R17 V167

Этот каталог содержит исходники **control.43** на основе официального Microduck **0.15.1**, использующего IPC API **40**. Соответствующая Robot Console — **R17 V167**.

V167 используется в паре с control.43. Обновление: исправлено дрожание корпуса.

- [Конфигурация, модели и установка прошивки](packaging/README.ru.md)
- [Сборка из исходников на новом компьютере](../docs/BUILD.ru.md)
- [Текущая базовая версия и границы проверки](../docs/BASELINE.ru.md)
- [Записи сборки и тестов V167](BUILDING-V167.ru.md)
- [Разработка в upstream-рабочем пространстве](CONTRIBUTING.ru.md)

Rust, Python, веб-страницы, модели и нативные программы синхронизированы с поставляемыми файлами. При публикации исходников упорядочены документация и указатели версий. Каждый робот по-прежнему должен использовать собственную калибровку суставов, направлений, пределов и IMU, которую необходимо проверить.
