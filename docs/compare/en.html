01 / WHAT MICRODUCK-KISSQY PROVIDES

Microduck-kissqy

From your first build
to advanced duck skills.

Microduck-kissqy brings software, hardware, policies, HD1910 print files, tutorials and Training Studio into one complete route.

01

A complete route from first build to advanced play

Software, hardware, supplied policies, HD1910-adapted print files, tutorials and a separate Training Studio are provided together.

Start with purchasing, printing, assembly, flashing, networking and local calibration; continue with everyday play, Chinese AI and new-skill training.

Full build route ↗
02

Supplied motions: no self-training for a normal build

Walking, sit/stand, picking, forward roll, both kicks, plus roller gliding, crouching, spinning and get-up resources.

This project is a major source of HD1910 motion resources in the community. Another image project credits 10 models to kissqy; use the models in each release package.

Policies and provenance ↗
03

A Chinese console with a published AI workflow

Graphical entry points for servo/IMU calibration, 3D pose, joint feedback, camera, gamepad and firmware maintenance.

R2 / V260 documents conversation, image recognition, voices/personas and action calling. AI needs service credentials and connectivity.

Console and AI setup ↗
04

Matching HAT, IMU and HUB hardware

Board designs, bills of materials, wiring, system image and firmware are provided together; build the boards or choose assembled ones.

V297 BATE also adds HAT servo numbering and midpoint calibration without URT2. Hardware acceptance of that test release remains pending.

Matching hardware ↗
05

HD1910 print files and step-by-step tutorials

STL / 3MF files adapted for the HD1910 build, with purchasing, assembly, wiring, flashing, calibration and troubleshooting guides.

Follow one reference configuration around ZERO 3W and 15 HD1910 servos, reducing the work of joining unrelated build routes.

Printing and assembly ↗
06

A separate Training Studio for new skills

The public Training Studio provides 14 motion families and 35 task recipes, with queues, SSH execution hosts, reward curves, simulation evaluation and ONNX export.

Finish your duck with supplied policies first. Long-training and hardware results remain specific to each task and its records.

Versions, compatibility and source material

Use each resource within its documented release and verification scope.

Which hardware is supported?+

The reference configuration uses ZERO 3W, 15 HD1910 servos and the published HAT / IMU / HUB revisions. Other boards, servos or mechanical changes require compatibility checks. Hardware details.

Are demonstrations the same as supplied policies?+

Use the published package and provenance for each policy. One-legged balance has a physical demonstration, but the provenance page has not matched it to a separately identified published weight. The video does not promise inclusion in the current package. Model scope.

Which features need separate verification?+

R2 / V260 is the current stable publication entry. The V297 BATE pre-release adds HAT numbering, midpoint calibration and hardware tests; its physical acceptance is pending. Listed training recipes do not prove every task has completed long training and hardware acceptance.

Where are the text comparison, evidence and licenses?+

The text comparison and source index remain available. Check the community model attribution and OpenMicroDuck policy directory. Some original content is restricted to personal noncommercial use; upstream and third-party material retain their component licenses.
