# Комплектная прошивка Microduck R17 V167 / control.43

<a id="microduck-r17-v167--control43-随包固件"></a>
<a id="microduck-r17-v167--control43-bundled-firmware"></a>
В исходном документе сборка `1fa8438-feetech-ft6-control.43` указана в паре с консолью `1.0.164` и официальной системой `0.15.1`. robotd и padd — ARM64-программы, скомпилированные для этой сборки; robotctl, mediad, мост ввода и установка используют конфигурацию соответствующего пакета.

> Примечание переводчика: номер консоли `1.0.164` в этом абзаце расходится с текущей [базовой версией](../../docs/BASELINE.ru.md), где control.43 соответствует R17 V167 (`1.0.167`). Исторические результаты проверки ниже сохранены как в источнике.

Устанавливайте через **系统维护 → 随包固件** («Обслуживание системы → Комплектная прошивка»). Пройдите четыре шага запуска служб, переключитесь в режим движения, выполните HOME и включите политику перед движением. Кнопки описаны в [руководстве пользователя консоли](../console/USER-GUIDE.ru.md).

Четыре роликовые модели, `manifest.json` и `deployment-contract.json` устанавливаются в `/opt/robot/feetech-ft5-r5/roller/`. В режиме роликов движение выполняет swizzle; A выбирает приседание или вращение, причём при входе по умолчанию выбрано приседание. Режим ходьбы предоставляет шесть конфигураций, с LB для удара левой ногой. Отдельный слот Stand пуст; физическая L3 позволяет тестировать восстановление на роликах при выполнении условий.

## Калибровка и параметры сервоприводов

Комплектная калибровка получена с подтверждённой сборки `duck-10e4`, её происхождение описано в `robot-calibration-source.json`. Все 15 направлений равны −1; ноль ID 30 — 2526, ID 31 — 2228, ID 33 — 1599; включена калибровка IMU.

При установке приоритет имеют действительная локальная калибровка и сохранённые параметры. При необходимости восстановление использует комплектную конфигурацию сборки. Рабочая калибровка — `/etc/robot/feetech-ft5/hd1910-calibration.toml`; конфигурация службы — `robotd.toml` в том же каталоге.

P сервоприводов следует контракту, сейчас P=5. Запись и восстановление при снятии крутящего момента затрагивают только один байт по адресу 50. Этот путь явно не записывает адреса 48/51; он восстанавливает P, сохранённый перед включением крутящего момента. Частота цикла управления — 50 Hz.

<a id="服务"></a>
<a id="services"></a>
## Службы

robotd управляет роботом через нативный IPC; padd принимает физический геймпад. Запуск, подключение и загрузка модели автоматически не запрашивают движение. Commissioning собирает обратную связь; режим движения загружает политики. После переключения модели включайте политику из HOME.

mediad запускает захват по запросу и засыпает после выхода последнего потребителя. Системная конфигурация отключает автоматическое обновление и пути восстановления golden, способные перезаписать этот пакет прошивки.

<a id="完整性与验证"></a>
<a id="integrity-and-verification"></a>
## Целостность и проверка

`BUILD.json` идентифицирует фактическую сборку; `ELF-CHECK.json` описывает нативные программы; `install-files.json` и `SHA256SUMS` определяют комплектные файлы / хеши. При установке проверяются количество переданных байтов, SHA256 и принадлежность ELF к AArch64.

В текущем целевом объёме пройдены 235 тестов Rust, загрузка и первый инференс шести обычных / четырёх роликовых моделей ARM64/QEMU, импорт продукта и проверки отдельных файлов. Полные журналы поставляются с исходниками. В этой записи сборки движение на роликах на физическом ZERO ещё не проверено.

Исходный контракт каждой роликовой модели задаёт коэффициенты для её активной сети. У восстановления исходный слот и `required_skill_settings` пусты; объявлен `manual_skill` с нулевыми командами. Пакет использует существующий путь навыков для теста 5 секунд по физической L3; padd проверяет режим роликов, активное состояние и классификацию падения по свежим данным IMU. Автоматический слот восстановления не добавляется. Пять секунд — локальная конфигурация теста; исходные контракты и веса сохранены. В имени обучающего архива указано 10000, но фактическая контрольная точка манифеста — 11000, и именно она определяет версию.
