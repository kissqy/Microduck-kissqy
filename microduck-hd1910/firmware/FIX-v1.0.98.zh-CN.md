R17 v1.0.98 / 官方 0.15.1：运动模式与紧凑中控更新

中控版本 1.0.98，正式服务 1fa8438-feetech-ft6-control.4。
本版继续使用原 R17 中控、UART / FT6 硬件适配和原凭据保存机制。没有采用另一个聊天窗口的中控或通信协议，没有刷写 HAT 或 IMU 固件。

安装
1. 关闭旧中控，将 Microduck-Console-R17-v1.0.98.zip 完整解压到新目录，运行 start.cmd 并连接 Zero。
2. 在手柄区域输入首次需要的 sudo 密码；已保存时可留空。
3. 支撑机身，在与 07、08 并排的“09 固件与电源”选择随包固件，点击“升级所选固件”。也可选择本版 Microduck-Firmware-R17-v1.0.98.zip。
4. 等待安装日志成功，并核对实际运行版本为 control.4。升级失败时页面保留具体原因和完整安装日志。
5. 手柄区域确认机身已支撑，切到运动模式。使用 Start 首次请求官方 HOME，等待缓动完成，再按 Start 启用策略。安装不自动回 HOME 或运动。

运动模式切换
代码中确认存在额外的前端/中控拦截：运动模式切换要求实时显示的 calibrated_count=15；该数值依赖实时关节样本和标定数据通道，不能代表本机保存文件是否完整。
本版将 R17 的模式切换作为服务管理操作，不再用实时画面的标定计数或姿态新鲜度拦住管理请求。切换前仍由本机 service.sh 调用 calibration-config.py 检查实际保存的 15 个关节、零位、方向、限位与 IMU 方向；检查失败不会启动运动模式。
连接状态新增本机保存标定的就绪检查，页面显示具体原因。实际模式优先使用服务总线报告，设备反馈过期时单独提示；缺少服务报告时使用已核对的实际进程模式。
未获得本次无法切换的实机新日志，因此不能断言额外拦截是唯一原因；sudo、保存标定或服务启动失败仍会以真实回执报告。
HOME、模型启动和关节动作的硬件安全检查继续保留。网页不额外创建自动保持、启停或摔倒恢复策略。

页面布局
• 删除独立“回到 HOME”卡片和它的网页按钮/绑定；HOME 由官方手柄 Start 执行。
• 模式切换与 sudo 输入合并到手柄区域，按钮横向并列。
• IMU 安装核对合并到关节工作台；桌面工作台与关节曲线同高。修复曲线画布的像素缓冲区意外撑高整行的问题。
• 第 09 固件与电源与 07 链路、08 原始报文同排同高；固件来源和电源按钮横排。新增明确的“重启固件”按钮，调用原 R17 reconnect-service，重启 robotd；“重启 Zero”仍是整机重启。
• 顶部新增 ZERO 温度，读取 system.cpu_temp_c。没有实时系统数据时显示横线。
• 手柄保留有纹理的外壳和键帽，采用紧凑布局，模型用横向按钮，手柄区域不使用下拉选择框。完整中文按键说明常驻显示。
• 4K 桌面三列各 840px，手柄与参数/说明内部并排；1600px 桌面三列各 1120px；1280px 窄桌面各 1250px；手机堆叠各 1210px。常规控制内容无需在卡片内下拉滚动。模型导入管理等低频操作可点击独立按钮展开，日志有独立滚动区。

三个滑条及回读
音量：0—100%，松开后写入原 R17 ALSA 软件音量，并核对实际 cset 回读；失败不伪装成功。升级时恢复原 R17 voice-setup 声音通道元数据与软件音量配置，继续由官方 robotd 声音引擎和官方 sounds 生成音库。音量通道无法配置时日志给出原因，运动服务继续启动，滑条保持不可用。
鸭嘴开合度：0—100%，通过网页 Xbox 帧里的 RT 模拟轴交给未修改的官方 padd；超过官方 RT 门槛会短叫。LT / RT 在图上是按住的扳机按钮，松开恢复鸭嘴滑条值；LT 与 RT 的最大值控制嘴巴。失焦、隐藏、暂停、真实手柄接管等情形清除网页嘴巴/摇杆输入。回中按钮也会清除网页鸭嘴值。这是输入控件，不是新的嘴部动作策略。
LB / RB：普通左、右肩键，不是滑条；当前没有踢腿模型，保持灰显。
全局动作缩放：0.1—1.0，步进 0.1；点击“应用”后先卸力、保存设置、重启并核对实际参数。只拖动滑条不会声称已生效；机器人回读值与待应用值分开显示。普通重启继续保留已保存的选择。起坐基础倍率固定 1.0，选择起坐时缩放滑条禁用。

相对 v1.0.97 新增的官方代码改动
唯一新增的官方主程序差异是 robotd/src/feetech_commissioning.rs 的部署标识更新为 control.4。实际官方策略、滤波算法、动作映射、padd 主程序和 tap 程序保持原样。
其余变更在原 R17 console 与 packaging：移除不恰当的实时显示计数拦截；新增只读保存标定检查；恢复原声音软件音量配置；恢复音量桥；重排页面、滑条和重启固件按钮。鸭嘴仍通过官方 RT 输入，没有增加直接写嘴舵机的接口。
对官方 0.15.1 的全部累计硬件、自训合同和只用自训模型改动，见附后的 OFFICIAL-CHANGES.zh-CN.md。
