## Протокол и совместимость

Адреса 56–70: гироскоп XYZ i16 little-endian (6 байт), кватернион XYZ binary16 little-endian (6 байт), затем счётчик выборок u8, состояние и резервный ноль (по 1 байту).

Бит состояния 0=не готово, бит 1=устарело, бит 3=не менее пяти новых выборок после последнего чтения. Хост также отклоняет ошибки бита 2; биты 4–7 должны быть нулевыми. Бит 3 сообщает о соотношении частоты выборки / чтения и не означает отказ датчика.

Счётчик увеличивается только при фактически новых кватернионах; переход 255→0 — нормальное переполнение. Перед передачей прошивка проверяет кешированные временные метки и устанавливает бит 1 при возрасте более 30 ms. Если выборка остановилась, но UART продолжает отвечать, данные не могут продолжать считаться свежими.

Хост проверяет состояние, три последовательных одинаковых значения счётчика, корректность кватерниона и бюджет 50 ms, объединяющий предел 30 ms с истёкшим временем полного цикла. Официальные преобразования установки и проверки готовности сохранены.

Адреса 124–143 предоставляют полный диагностический формат из 20 байт: 12 основных байт, последовательность u32, возраст u16, ready, schema=1. При обычном управлении эта область не опрашивается.

Это соответствует быстрому 15-байтовому формату сообщества. Диагностика, идентификатор прошивки и низкоуровневая реализация определяются проектом. ID200 должен идти первым в Sync Read; другая логика порядка, не проверенная физически на этой HAT, не переносится.

Текущая прошивка использует приём USART по прерываниям, быстрые ответы ISR, публикацию через двойной буфер, ожидание TC перед освобождением шины, восстановление RX перед отключением драйвера, исходную инициализацию GPIO / SPI / IMU, SFLP 120 Hz и документированное поведение светодиода.

Меняются только существующая серверная часть Feetech и точка входа службы; официальный порядок суставов, файлы калибровки и политики сохраняются. Для совместимости ключи конфигурации и пути продолжают использовать `feetech-ft5` / `feetech-ft5-r5`; эти пути не означают, что работает старая прошивка. Запуск остаётся со снятым крутящим моментом и не включает автоматически политику XL330.

## Сборка

Используйте Arm GNU Toolchain 14.3.Rel1:

```bash
make -f Makefile.feetech TOOLCHAIN=/path/to/toolchain/bin/arm-none-eabi-
```

Перед компиляцией подготовьте STM32CubeG0 с CMSIS Core из зафиксированного коммита `446ebe396489ca75679caa80887d7257efe92e3d` и подмодулем устройства `f576c24e123edf3332988ecd49512c0f35f85186`.
