## 新增与本轮累计功能

- **四个独立工作模式**：IMU / HAT / HUB 测试、舵机编号、关节标定、机器人运动。左侧直接切换，初次启动显示准备页，SSH 连接后按实际状态引导。
- **通过 HAT 进行舵机编号**：扫描 ID 1–250，显示扫描进度并可停止；列表显示实际位置、对应关节与编号状态，选择目标编号保存；支持按界面提示交换两颗已编号舵机的关节编号。
- **单颗中位校准**：把所选舵机当前位置设为 2048，只更新相关舵机，不要求重扫整个列表；之后需重新标定该关节。
- **独立硬件测试**：查看 IMU 姿态、麦克风收音电平，播放扬声器鸭叫并观察播放电平；接线参考白底图放在测试页。
- **手柄操作说明**：实物转绘手柄保留可操作位置、说明和呼吸光晕。摇杆及运动操作需先 HOME 并进入保持；卸力与叫声不受保持状态限制。
- **标定与运动布局**：标定工作台按操作分列，保留较高的 3D 模型；运动模式 AI 独立一列，全关节反馈与关节曲线集中显示，摄像头、ToF 与系统状态更易查看。
- **中文 AI 交互继续保留**：延续原有中文对话、音色与角色配置、视觉识别和动作调用；本轮重点调整其在运动页面中的布局。

## HAT 舵机编号方法

1. 按测试页接线参考连接 ZERO、HAT 和舵机电源，在电脑端启动中控并通过 SSH 连接 ZERO。
2. 左侧进入 **舵机编号**。未编号或可能重号的舵机，**一次只接一颗**，避免多个同 ID 舵机互相冲突；已确认编号不同的舵机可以串联。
3. 执行扫描，选中识别到的舵机，核对实际位置与对应关节，选择目标编号并保存。
4. 右腿使用 **10–14**，左腿使用 **20–24**，颈头使用 **30–34**；左右以机器人自身为准。**ID 200 是 IMU**，不作为关节舵机改号。
5. 逐颗编号完成后再连接整链并扫描核对，随后进入关节标定。中位校准后须重新标定相应关节。

首次运动仍按 **核对本机标定 → HOME → 保持 → 运动** 操作。
