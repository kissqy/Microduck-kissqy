# R17 v1.0.157-Fix1

这是 v157 的 PC 中控修正版。随包固件仍为 control.35，固件压缩包、原生程序、Rust 源码、模型及机器人安装流程均未改变；已安装 control.35 不需要重刷。

## 本次修改

- 删除模型区重复的“执行右脚踢球”按钮、事件绑定、禁用条件、请求映射，以及它独用的维护 run-skill 校验和 robot.do 转发分支。模拟手柄 RB 通过官方输入 IPC 执行右踢，模型选择和模型文件保留。
- 切模式保留健康的网页 WebSocket 和输入 SSH。开始交接时一次性清除旧输入；结束时复用输入通道，清除旧 IPC 和按键绑定，不携带旧动作。普通状态拒绝保持连接，真实通信错误仍恢复连接；关机、切换 SSH 目标或退出时按原流程关闭。
- RB、A、X 和方向键下基于已收到的实时反馈、模型、HOME、策略、IMU 和扭矩状态禁用。按钮不可用时不发请求；反馈与点击发生竞争时，服务仍作最终判断，拒绝后清空输入、不重发动作。Start、Select 和叫声键保留原用途。
- 机器人数据订阅确认后清除该端点的旧反馈、标定缓存和错误，保留独立 ToF 与原始遥测会话代次。四步启动事件进入网页和后台快照；初始化等待显示等待，失败保留模块及原始原因。显式服务重启造成的旧端点 EOF 作为正常交接；真实 SSH 错误、协议损坏、非预期断线仍显示失败。
- 默认系统日志保留启动四步、主动操作结果和真正失败原因，同一步重复成功合并。完整模型 JSON、SSH 通道开关、命令输出及 ALSA 明细进入详细日志。两个日志使用原有一个写入线程；退出排空并释放两个文件。

## 使用

退出旧中控脚本，完整解压新包后照常启动。已安装 control.35 直接连接，不需安装固件。系统日志可分别下载流程日志和详细日志。

## 验证边界

离线回归覆盖输入映射、实体手柄接管、旧动作丢弃、连接保留、按钮禁用、数据交接、原始字节转发、日志脱敏及关闭文件。使用本机 TCP 验证生产请求和 WebSocket；执行环境禁止直接 AF_UNIX 创建，相关请求测试仅在 OS 套接字边界替换为 loopback TCP。没有连接实机，也没有在原生 Windows 上执行，不能据此宣称摔倒、IMU 启动和蓝牙无线稳定性已验证。

未新增设备轮询、UART 读取、50 Hz 循环工作或模型推理。原 v157 原生测试结果属于历史记录，不作为本次新通过的结果。
