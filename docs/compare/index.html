01 / 我们的优势

Microduck-kissqy

从 0 到进阶，
一套完整的鸭鸭复刻方案。

Microduck-kissqy 把软件、硬件、模型、飞特适配打印件、教程和训练中控连成一条完整路线。

01

从零制作到进阶，资料与工具完整配套

软件、硬件、现成运动模型、飞特 HD1910 适配打印件、各类教程和训练中控集中提供。

按采购、打印装配、刷机配网和本机标定开始，再继续日常玩法、中文 AI 与自训新动作。

完整制作路线 ↗
02

配套现成动作，正常复刻无需训练

行走、坐下站起、捡取、前滚翻、左右踢球，以及滑轮滑行、蹲下、原地转和倒地起身。

本项目是社区 HD1910 动作资源的主要来源。外部镜像将其中 10 个模型作者标为 kissqy；具体模型按发布包使用。

中文中控与 AI，装好后继续玩

舵机与 IMU 标定、3D 姿态、关节反馈、摄像头、手柄和固件维护，都有中文操作入口。

R2 / V260 提供中文对话、拍照识别、音色角色与动作调用；AI 需配置服务凭据并联网。
