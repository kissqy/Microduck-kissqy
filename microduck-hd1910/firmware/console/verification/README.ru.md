# Записи проверки R147

`3d-audit147.json` фиксирует объём проверки, численные тесты, исходные хеши и пределы приёмки. `r146_*` содержит независимые сравнения с отображением R146. Все проверки направлений модели используют рабочие Three.js и DuckView без подключённых сервоприводов.

После установки Node.js откройте терминал в каталоге консоли и повторите:

```bash
node verification/test_calibration_reference.mjs
node verification/test_calibration_reference.mjs verification/reference_training_8d0db749.xml
node verification/test_pose_state.mjs
```

Первая проверка использует встроенную рабочую модель, вторая — XML обучения из зафиксированного коммита 8 d 0 db 749, третья проверяет порядок обратной связи, отсутствующие значения, старые целевые значения и состояние IMU. XML используется для независимых расчётов преобразований, а не для запуска MuJoCo из этого каталога.

Эти проверки не запускают браузер и не отправляют команды сервоприводам. Визуальное отображение в браузере и физический робот пользователя этой записью не приняты. Численные проверки не доказывают, что проблема физического переворота решена.
