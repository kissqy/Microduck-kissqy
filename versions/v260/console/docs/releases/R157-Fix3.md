# R17 v1.0.157-Fix3

本版仅修改 PC 中控。随包固件仍为 control.36，与 157-Fix2 的固件压缩包、安装文件、原生程序、Rust 源码及模型逐字节一致。已安装 control.36 无需重刷；早于 control.36 仍需安装随包固件才能应用此前的 IMU 启动确认修复。

## 本次调整

- 删除截图中的重复区域：额外服务状态栏、行走预检和四步摘要，以及它们专用的文字计算、DOM 更新、位置迁移、导出按钮绑定和样式。保留原位置的服务模式、关节／IMU 状态、网页手柄、错误提示及系统日志 1/4～4/4 流程。导出记录仍使用原记录入口。机器人就绪判断和实际输入禁用条件不变。
- 模型目录与按键槽的 JSON 是供界面使用的查询数据，模型对象同时出现在 models 与 slots，过去被通用 SSH 日志原样打印，形成重复。现在该自动查询由模型模块记录开始、结果及错误，返回给界面的数据不变。成功日志显示模型数量及未配置槽，不再转印模型路径、合同、哈希和重复 JSON。
- 自动服务进程查询由该模块记录实际版本、模式和串口结果，完整数据仍返回界面。
- Linux 音量助手返回 PCM Playback Volume、Line Playback Switch 的底层 amixer 参数。75,75 为左右声道原始寄存器值，不是 75%；本项目对数换算后约为 5%，on,on 表示输出开启。自动读取现在只记录实际百分比；设置成功记录实际回读与保存结果。失败、无效回执及真实命令错误保留原因，初次音量未确认不会打印 None% 成功，也不影响机器人或手柄输入服务。
- 成功的自动 JSON 查询使用原持久 SSH 通道的普通结果返回，减少逐行进度转发。日志文件本身没有来源过滤；四步启动、主动操作、完整安装输出、其他命令及异常仍沿用同一完整日志和原写入线程。查询命令失败或 JSON 损坏时保留原始 stdout／stderr。不增加查询、轮询、线程、服务依赖或正常 50 Hz 工作。
