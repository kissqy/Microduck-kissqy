# R1.5.16 一次部署修正版

## 使用

关闭旧本机中控，完整解压本修正版并启动。在SSH服务器区填写连接信息和密码，点击“部署并准备环境”。首次连接按页面核对主机指纹并确认，流程随即继续。缺少ensurepip/venv的部署也使用这个按钮，不需要手工删除bootstrap目录或逐个安装组件。

执行顺序：检查已有工具 → 一次安装缺少的系统组件 → 复用或准备独立uv → 上传并连接后台 → 自动准备固定版本训练环境 → CUDA和官方任务检查。环境就绪后再加入队列、开始训练。部署不会自动开始模型训练。

## 自动补齐范围

- Ubuntu/Debian系统缺少Python时安装Python3及venv；中控Python最低3.10，固定训练环境由uv使用Python3.12。
- 当没有可用uv且venv/ensurepip不可用时，安装与系统Python对应的`python3.X-venv`及`python3-venv`。这会处理Python3.12报ensurepip缺失的情况。
- 检查git、系统证书和服务器的OpenMP/EGL/GL库，仅安装缺少项；有缺项时一次更新包索引，合并安装。
- 查找PATH、`~/.local/bin/uv`、`~/.cargo/bin/uv`及工作目录的`bootstrap/bin/uv`，验证可执行后复用。没有可用uv才在独立bootstrap准备。
- 固定训练源码继续使用原0.15.1对应提交和`uv sync --frozen --python 3.12`，不改变训练动作系数、滤波、P或模型合同。

root账号直接安装。非root账号先尝试已有免密码sudo；密码SSH账号可将本次登录密码经加密SSH的标准输入交给sudo。密码仅在内存，不写入文件、日志或进程参数。账号必须有安装缺少系统组件的权限；密钥账号若没有免密码sudo，使用root或有sudo权限的密码账号完成首次部署。

## 复用与训练连续性

已准备好的系统组件不会重复安装。相同工作目录里已运行的R1.5.16后台会继续复用，不主动关闭后台训练或启动第二个后台。已就绪环境不会重复安装；以后使用“连接/重连”时不执行系统安装。版本仍为R1.5.16，方便继续连接已有服务。

本机WSL测试同样复用已有uv和训练环境；测试模式不安装服务器图形/OpenMP库，也不自动同步正在使用的训练仓库。保留`/usr/lib/wsl/lib/nvidia-smi`查找修复。

部署只补齐用户态依赖，不重装NVIDIA驱动、不重启机器。服务器必须已分配GPU，且能访问系统包、Python包和源码下载服务；真实CUDA结果以环境检查为准。

## 验证

自动化测试覆盖：缺少Python3.12 ensurepip的匹配安装、合并系统库安装、重复部署跳过安装、cargo目录uv复用、失效bootstrap工具、sudo密码经标准输入使用及缺少权限时提前停止。SSH协议测试覆盖密码和密钥传输、后台复用、断线重连、模型上传及下载隧道；界面处理器、训练队列和WSL/GPU状态回归同步验证。

这些验证使用隔离测试环境，没有连接用户的首尔服务器或启动GPU训练。
