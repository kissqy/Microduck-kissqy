# 🦆 Готовый образ системы Microduck R1

**Запишите образ, подключитесь к Wi-Fi и откройте консоль, чтобы запустить свою утку!**

Этот образ для Radxa ZERO 3 W основан на официальном Microduck 0.15.1 от Pollen Robotics. В нём предустановлены адаптация прошивки под Feetech HD1910, службы робота и модели движений из этого проекта. **Компилировать или по отдельности устанавливать ПО на ZERO не требуется.**

> ✅ **Настоящая ZERO прошла проверку установки чистого образа:** работали загрузка, настройка точки доступа при первом запуске, подключение к домашнему Wi-Fi, SSH, связь по шине робота и распознавание в консоли R17. Движение и качество моделей на другой сборке всё равно требуют локальной проверки.

<a id="-三步上手"></a>
<a id="-three-steps-to-start"></a>
## 🚀 Три шага для начала

**① Запишите систему**

Скачайте `microduck-zero3w-0.15.1-R1.img.xz` из этого выпуска.

Используйте **[Armbian Imager](https://imager.armbian.com/)**; также доступны [установщики на GitHub](https://github.com/armbian/imager/releases). Выберите собственный образ и карту microSD, затем запишите его. **Вручную распаковывать `.img.xz` не нужно: Armbian Imager делает это автоматически.**

**② Подключитесь к точке доступа и настройте домашний Wi-Fi**

Вставьте карту в Radxa ZERO 3 W, включите питание и подключитесь:

- Сеть: `Microduck-kissqy`
- Пароль: `12345678`

На странице настройки введите параметры домашнего Wi-Fi и новый пароль входа в систему. Если страница не открылась автоматически, перейдите на `http://10.42.0.1:8088`.

**③ Откройте консоль с китайским интерфейсом**

Запустите Microduck R17 на компьютере и подключитесь к ZERO для просмотра камеры, положения в 3D, суставов и состояния IMU. Перед использованием физического геймпада **проверьте нулевые положения, направления, ограничения и установку IMU именно своей сборки с 15 суставами**, затем выполните HOME, удержание и движение.

## 📦 Версии

Образ содержит прошивку и модели для ZERO. **Консоли Windows — отдельные инструменты**, которые не устанавливаются автоматически на компьютер при записи образа. Онлайн-демонстрации репозитория показывают более ранние версии с имитационными данными и не управляют настоящим роботом.

> Примечание к русскому переводу: таблица и описание демонстраций выше сохраняют состояние на момент выпуска R1. Текущий комплект репозитория — V167 / control.43; сам образ R1 по-прежнему содержит control.40. Для обновления установите прошивку из V167. Актуальная версия демонстраций указана на [главной странице](../../README.ru.md).
