# Самостоятельно обученные модели R17 v1.0.137 / официальной версии 0.15.1

<a id="r17-v10137--official-0151-self-trained-models"></a>
Порядок запуска / установки описан в [руководстве консоли](console/USER-GUIDE.ru.md) и [руководстве комплектной прошивки](packaging/README.ru.md). Комплектные модели: учитель ходьбы по пересечённой местности 14000 итераций, посадка / вставание 10000, подбор с земли 5000, кувырок вперёд 10000 и учитель восстановления LB 11000. Автоматический Stand пуст; LB использует официальный именованный навык `stand_test`; удержание на месте использует Walk.

Эта версия заменяет только модель LB и поддерживает её контракт без фильтрации. Исходные контракты и веса сохранены побайтово. Источники параметров и пропуск фильтра для отдельных моделей описаны в [проектировании настроек](docs/design/r17-settings-design.ru.md). Калибровка обучения сохранена как информация о происхождении; при установке по-прежнему используется собственная калибровка сборки робота.
