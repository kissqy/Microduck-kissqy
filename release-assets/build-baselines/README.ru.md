# База для воспроизводимой сборки

Один ZIP консоли V164 сохранён для воспроизведения полного установщика V167 на основе исходного комплекта. Для текущих установок используйте V167; см. [загрузки](../README.ru.md). Скрипты сборки проверяют зафиксированную SHA256 архива, не размещая ещё одну его копию в исходниках.
