## 📦 下载与使用

中控运行包请下载本页下方 **Assets** 中的 **`Microduck-Console-Studio-V302.zip`**，以实际上传的附件为准。GitHub 自动生成的 **Source code (zip／tar.gz)** 是仓库快照，不能替代中控运行包。

1. 关闭正在运行的旧中控，将 ZIP **完整解压**到新目录。
2. Windows 运行 `start.cmd`；macOS／Linux 运行 `bash start.command`。
3. 浏览器打开 `http://127.0.0.1:8090`，使用 ZERO 的实际 IP、用户名和系统密码连接。
4. 按需进入硬件测试、舵机编号、关节标定或机器人运动。

**升级规则：**

| 当前版本 | 本次操作 |

## ✨ 相比 V260 的累计功能

- **四个独立工作模式**：IMU／HAT／HUB 硬件测试、舵机编号、关节标定、机器人运动，按操作阶段切换。
- **通过 HAT 给舵机编号**：无需另接 URT2；支持手动扫描、编号保存、编号互换及单颗中位校准。
- **独立硬件测试**：查看 IMU 姿态、麦克风收音电平，播放扬声器鸭叫；配套白底接线参考图。
- **完整 3D 参考工具栏**：标定页与运动页均可查看实测、零位、HOME 站姿和关节正／负方向。参考姿态只改变屏幕显示，不驱动实机。
- **IMU 与关节曲线并排**：标定、运动页面恢复姿态仪与关节曲线双列布局，方便同时观察。
- **保留已有中文 AI 功能**：中文语音、音色与角色配置、视觉识别及已有动作调用继续使用；AI 服务凭据需自行配置。

## ⚡ V302 重点优化

- **普通改号减少重复扫描**：复用同一维护会话内的有效扫描结果，核对所选舵机与目标编号，写入后读回确认；保留手动全扫描。
- **中位校准减少重复等待**：复用现有监测链路，按实际读回结果确认完成；保留位置、偏移、卸力与回锁核对。
- **复用维护通信会话**：连续操作减少重复建立转发进程与认证的开销。
- **编号／测试进入检查优化**：条件未变化时，短时间内复用有效检查结果；接线、连接、服务占用或组件状态变化后重新检查。

## 🔧 累计修复与界面调整

- 修复缺 IMU、缺舵机时硬件初始化等待卡住、难以切换到测试或编号的问题。
- SSH 连接状态与机器人服务状态分开显示，正常停止总线不再误报为运动故障。
- 扫描、改号与中位校准在原位置反馈进度和结果，普通页面切换减少不必要的重载。
- 恢复运动页的零位／HOME 参考选择，并在状态回读后保持；点击「实测」恢复随动。
- 调整 3D 左右标签的避让及左下角文字排版，减少与参考工具、坐标说明重叠。
- 保留原有故障日志，增加具体设备 ID 与中文原因；固件、电源和手柄修复入口更集中。

## 🔢 HAT 舵机编号与中位校准

1. 按硬件测试页的接线参考连接 ZERO、HAT 与舵机电源。
2. 进入「舵机编号」，**先手动扫描一次**。未编号或可能重号时，**一次只接一颗舵机**。
3. 选中识别到的舵机，核对位置与目标关节，再保存编号。右腿 **10–14**、左腿 **20–24**、颈头 **30–34**；左右以机器人自身为准。
4. **ID 200 是 IMU**，不作为关节舵机改号。
5. 改变接线、增减设备、重新上电或连接异常后，重新扫描。中位校准后重新标定相应关节。

首次运动按 **核对本机标定 → HOME → 保持 → 运动** 操作。
