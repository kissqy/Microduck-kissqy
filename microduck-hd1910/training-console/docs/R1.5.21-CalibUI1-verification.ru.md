Microduck Training Studio R1.5.21 / CalibUI1

Сформировано из фактического полного ZIP R1.5.21 Public. Новый пакет изменяет только отображение локальной страницы калибровки:
- используются китайские названия из списка сервоприводов R17 в реальном времени + (номер ID);
- при сравнении сохранённой калибровки с заново полученной калибровкой ZERO подсвечиваются только соответствующие различающиеся поля;
- направление, ноль энкодера, механический нижний предел, механический верхний предел, физический ID и состояние калибровки независимо показывают предыдущие значения;
- вся строка больше не подсвечивается, столбец нулевой точки не подсвечивается безусловно.

Проверки:
- `node tests/test_calibration_field_ui.cjs` → PASS (15 ID; 7 независимых случаев изменения).
- `python -m unittest discover -s tests -p test_zero_calibration.py` → PASS (9 тестов).
- `python -m unittest discover -s tests -p test_official0151.py` → PASS (из 12 тестов 1 пропущен из-за отсутствия закреплённых исходников).
- `python -m unittest discover -s tests -p test_servo_mass.py` → PASS (из 8 тестов 5 пропущены из-за отсутствия MuJoCo).
- `node --check training/static/studio.js` → PASS.
- Среда выполнения Chromium блокировала все переходы (net::ERR_BLOCKED_BY_ADMINISTRATOR), поэтому приёмка по реальным снимкам экрана не пройдена; эта проверка не отмечается как успешная.

Закреплены без изменений: data/task-configs/**, ядро обучения и модули исполнительных механизмов, официальные указатели, логика экспорта модели, протокол SSH-сервера и RELEASE=R1.5.21.
