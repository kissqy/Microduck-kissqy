# Структура репозитория и повторяющиеся ресурсы

<a id="固件源码已经公开"></a>
<a id="firmware-source-is-public"></a>
## Исходники прошивки опубликованы

Текущий выпуск: **R17 V167 / control.43**. Исходники прошивки на Rust и адаптации Feetech находятся в [firmware/](../microduck-hd1910/firmware/README.ru.md); исходники консоли — в его каталоге `console/`. См. [инструкцию по сборке](../microduck-hd1910/docs/BUILD.ru.md).

<a id="为什么还会看到较大的文件"></a>
<a id="larger-files"></a>
## Крупные файлы

| Содержимое | Расположение и назначение |
| --- | --- |
| Готовые загрузки | ZIP-архивы консолей в `release-assets/`, отдельная прошивка в `firmware/console/updates/`. |
| Настройки обучения и справочные данные | `microduck-hd1910/training-console/data/`, используются локальной консолью обучения. |
| Ресурсы онлайн-демонстраций | `docs/`, каталог публикации GitHub Pages; копии геометрии и параметров обучения обеспечивают независимость демонстрации. |
| База для воспроизводимой сборки | Один зафиксированный ZIP V164 в `release-assets/build-baselines/`, используемый для воспроизведения установщика V167. |
| Исторические справочные материалы | `firmware/verification/official-reference/`, где находятся зафиксированные исходники upstream, модели и исходные записи получения данных. |

Git использует один объект файла для одинакового содержимого по разным путям, тогда как полный ZIP каталога содержит каждый путь отдельно.

<a id="本次整理"></a>
<a id="cleanup"></a>
## Очистка

- Объединены одинаковые снимки official-reference с сохранением исходных байтов и записей происхождения. Старый дублирующий каталог удалён; соответствие SHA256 сохранено в `REFERENCE-LAYOUT.json`.
- Удалён дублирующий псевдоним модели удара левой ногой, каталог документации перенаправлен на действующий каталог.
- Удалены неиспользуемые скрипты сборки V160/V162/V163, упаковщик V147 и устаревший отдельный тест вставания; текущая точка входа сборки — V167.
- Две исторические двоичные копии модели вставания восстанавливаются из `policies/stand/` через `prepare-V167.py` с проверкой контрольных сумм, сохраняя старые пути тестов.
- Подписи онлайн-демонстраций обновлены до V167 / control.43; телеметрия остаётся имитационной.
- Добавлены страницы навигации для архивных относительных ссылок без изменения байтов исходных снимков.

Скомпилированная прошивка, ZIP-архивы консолей, веса моделей и данные настроек обучения сохраняют опубликованное содержимое. История Git сохранена, поэтому старые крупные файлы могут оставаться в исторических объектах.
