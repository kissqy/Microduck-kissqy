01

A complete route from first build to advanced play

Software, hardware, supplied policies, HD1910-adapted print files, tutorials and a separate Training Studio are provided together.

02

Supplied motions: no self-training for a normal build

Walking, sit/stand, picking, forward roll, both kicks, plus roller gliding, crouching, spinning and get-up resources.

Versions, compatibility and source material

Use each resource within its documented release and verification scope.

Which hardware is supported?+

The reference configuration uses ZERO 3W, 15 HD1910 servos and the published HAT / IMU / HUB revisions. Other boards, servos or mechanical changes require compatibility checks. Hardware details.

Are demonstrations the same as supplied policies?+

Use the published package and provenance for each policy. One-legged balance has a physical demonstration, but the provenance page has not matched it to a separately identified published weight. The video does not promise inclusion in the current package. Model scope.

Which features need separate verification?+

R2 / V260 is the current stable publication entry. The V297 BATE pre-release adds HAT numbering, midpoint calibration and hardware tests; its physical acceptance is pending. Listed training recipes do not prove every task has completed long training and hardware acceptance.

Where are the text comparison, evidence and licenses?+

The text comparison and source index remain available. Check the community model attribution and OpenMicroDuck policy directory. Some original content is restricted to personal noncommercial use; upstream and third-party material retain their component licenses.
