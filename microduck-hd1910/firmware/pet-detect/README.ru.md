# pet-detect

Небольшой аудиоклассификатор, распознающий почёсывание головы робота, где установлен микрофон. CNN размером около 20 KB по 40-полосным log-mel-окнам, инференс менее миллисекунды.

Перенесён из `apirrone/microduck_pet_detect`; обработчик arecord и наблюдатель окружающих звуков из прототипа `pet_worker.rs` также находятся здесь, поэтому всё, что слушает микрофон, собрано в одном crate. `robotd` запускает обработчик (см. `[audio]` в `deploy/robotd.toml`) и воркует при начале поглаживания.

- **Библиотека:** `PettingDetector` (потоковая обработка, гистерезис) и `worker::PetHandle` (подпроцесс arecord + каналы событий).
- **`pet-detect`** (программа): передайте в неё поток `arecord -D plughw:aic3104,0 -f S16_LE -r 16000 -c 1 -t raw` и наблюдайте вероятность, почёсывая голову.
- **`pet-features`** (программа): выгружает log-mel-признаки WAV — обучающая часть контракта одинаковой обработки при обучении и инференсе.
- **`models/pet_detect.onnx`**: обученная модель, поставляемая в выпуске как `models/pet_detect.onnx`.

<a id="retraining"></a>
## Повторное обучение

`training/train.py` (PyTorch) извлекает признаки ЧЕРЕЗ программу `pet-features` — тот же путь кода, который выполняет робот, поэтому расхождения обучения / инференса нет. Запишите данные на роботе:

```bash
arecord -D plughw:aic3104,0 -f S16_LE -r 16000 -c 1 -d 30 /tmp/petting_01.wav
```

в `data/petting/` и `data/normal/` (ходьба, моторы, окружение — всё кроме поглаживания; сами записи здесь не поставляются), затем:

```bash
cargo build --release -p pet-detect --bin pet-features
uv run --with torch --with onnx training/train.py
```

и закоммитьте обновлённый `models/pet_detect.onnx`.
