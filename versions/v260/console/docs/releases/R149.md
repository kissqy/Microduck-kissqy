# Microduck R17 v1.0.149 — 基于 v1.0.148 替换前滚翻与低头捡取

本版以 v1.0.148 中控和管理逻辑为基线，不回退联合 Walk 设置。

- Walk：仍为 `1cbf8730eadd75a5704332c9f3c10f60`，模型绑定基础缩放 1.00、头滤波 0.50、腿滤波 0.70。
- 前滚翻：替换为 10000 轮 / 4096 环境新模型 `59e15d7b04d0c40e9b11b8a70bdecae6`，基础 1.00、头腿直通。
- 低头捡取：替换为 10000 轮 / 4096 环境 Backlash 新模型 `b14e3a8b56ddbb8d2d831e727774a168`，基础 1.00、头腿直通。
- LB 起身、起坐、本机标定、v1.0.148 联合缩放滑条和其他保存参数保持。

本版原生 `robotd` 使用已经构建和验证过的新动作模型兼容二进制 `1fa8438-feetech-ft6-control.30`；没有声称在当前环境重新编译。

安装：关闭旧中控，完整解压本 ZIP，启动后连接 Zero，在“系统维护 → 随包固件”安装一次配套固件。无需恢复默认设置。
