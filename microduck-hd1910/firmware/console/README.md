# 🎮 Microduck 机器人中控 · R17 V167

连接真实机器鸭的中文控制台：查看姿态与设备反馈、完成关节和 IMU 标定、操作手柄、管理运动模型及维护机器人固件。

**当前配套：Radxa ZERO 3W · 飞特 HD1910 · Microduck 官方 0.15.1 · control.43 固件。**

[⬇️ 下载完整机器人中控 V167](https://github.com/kissqy/Microduck-kissqy/raw/refs/heads/main/release-assets/Microduck-Console-R17-V167.zip) · [详细使用及手柄按键说明](README.zh-CN.md) · [项目首页](../../../README.md)

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 实时 3D 与设备反馈 | 查看机器人姿态、15 个舵机的反馈、关节曲线及 IMU 身体姿态。 |
| 关节工作台 | 核对本机零位、方向、限位和 IMU 安装数据，完成装配后的标定。 |
| 手柄控制 | 使用实体手柄操作行走、起坐、捡取、滚翻、踢球和滑轮动作；页面提供中文按键说明。 |
| 模型管理 | 查看已安装模型和部署参数，按支持的模型类型导入自训模型。 |
| 摄像头 | 点击连接后查看头部摄像头画面，按需开始和结束视频会话。 |
| 系统维护 | 查看 ZERO 状态，调整音量，安装随包机器人固件，执行重启和关机。 |
| 记录与回放 | 导出观测记录，在关节曲线和 3D 视图中回看调试过程。 |

V167 配套固件包含 **10 份运动模型：6 个常规模型、4 个滑轮模型**。具体按键、模式切换、动作条件及部署参数由[详细使用说明](README.zh-CN.md)统一说明。

## 下载与启动

完整解压上方的运行 ZIP，进入包含 `start.cmd` 的目录。电脑需要能够运行 Python 3 和 OpenSSH 的 `ssh` 命令；建议使用 Python 3.10 或更新版本。

| 电脑系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start.cmd`。启动脚本使用电脑上已安装的 Python。 |
| macOS / Linux | 在本目录执行 `bash start.command`。 |
| 直接运行 Python | 在本目录执行 `python3 console.py --dashboard --feetech --open`。 |

启动后浏览器会打开中控；也可以手动访问 **http://127.0.0.1:8090**。保持启动窗口运行。

本目录源码也使用上述入口。普通使用推荐下载完整运行 ZIP，里面包含页面资源和随包固件。

## 第一次连接鸭鸭

1. 将电脑和 ZERO 接入同一局域网，确认 ZERO 已启动并知道其 IP。
2. 在页面顶部填写 **SSH 地址**，格式为 `用户名@机器人IP`；例如 `radxa@你的机器人IP`。
3. 填写 **SSH / sudo 密码**，点击“连接”。已保存凭据或已配置免密时，可按页面提示留空。
4. 等待机器人服务启动 **1/4～4/4** 完成，查看设备反馈、IMU 状态和模型加载结果。
5. 第一次装配或更换舵机后，在关节工作台核对自己的零位、方向、限位和 IMU，再执行 HOME 回位。
6. 回位完成后启用运动策略，通过手柄操作。实体手柄接入时，页面动作输入会让位给实体手柄。

使用已发布的整合系统镜像时，机器人服务已经预装。其他已有系统需要安装或升级配套服务时，使用中控“系统维护 → 随包固件”。已有 control.40 或更早版本的 ZERO，需要通过 V167 安装随包固件，升级到 control.43。

## 日常操作

- **走路与动作：** HOME 回位后启用策略，再使用摇杆和动作按键；Start 的具体行为、起坐、踢球、滚翻等映射见[手柄说明](README.zh-CN.md#其他按键)。
- **滑轮：** 使用实体手柄切换行走／滑轮模式及滑轮动作，操作顺序见[滑轮说明](README.zh-CN.md#实体手柄滑轮操作)。
- **标定：** 使用这台机器自己的装配数据，关节与 IMU 的操作见[标定与设置](README.zh-CN.md#标定与设置)。
- **结束使用：** 先通过页面或手柄卸力；退出电脑端中控时，在启动终端按 Ctrl+C 并等待退出。
