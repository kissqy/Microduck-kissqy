# R17 v1.0.157-Fix9

修复配对后 BlueZ 临时报告 Connected:yes 导致跳过 HID 连接的问题。首次／重新配对完成后始终连接一次 HID；普通修复遇到蓝牙已连但实体输入缺失时也只补这一层，不删除配对。连接失败保留目标地址与配对，显示 BlueZ 具体错误，蓝牙断开不再笼统归因 robotd。机制详见 [R17 连接设计](../../../docs/design/r17-connection-design.md#gamesir-连接与按层修复fix9)。

本次只改中控中的手柄修复 helper，主服务四步、安装顺序、数据连接、网页互斥、官方 padd 和 R7 桥接均保持 Fix8 原件。随包固件 SHA256 与 Fix8 相同；已安装 Fix8 的用户无需再次安装固件。

验证包括配对临时连接但无 HID、旧配对补接、HID 连接失败／超时、等待中蓝牙断开、AlreadyConnected 回执和既有流程回归。未连接机器人实机，日志符合已修复的失败路径，不能据此保证无线链路没有其他故障。
