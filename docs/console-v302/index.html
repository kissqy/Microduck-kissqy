Workspaces

四个模式，按当前步骤操作。

先通过 SSH 连接 ZERO，再从左侧进入需要的工作台。测试和编号入口可用于处理缺设备或接线问题。

01 / TEST

IMU / HAT / HUB 测试

查看 IMU 姿态和麦克风电平，播放扬声器鸭叫。同页查看白底接线参考图，先确认基础硬件。

02 / NUMBER

舵机编号

手动扫描总线，查看实际位置与对应关节，保存目标编号。支持单颗中位校准和按提示交换关节编号。

03 / CALIBRATE

关节标定

按操作分列，保留较高的 3D 模型。核对每个关节的方向、零位与限位，缺设备时显示具体故障。

04 / MOTION

机器人运动

实物转绘手柄附操作说明，集中显示全关节反馈、曲线、摄像头和 ToF，中文 AI 独立一列。

HAT / Servo ID

用 HAT 给舵机编号，按这四步来。

  1. 接好 HAT，并连接 ZERO

    按测试页接线参考连接 ZERO、HAT 与舵机电源。在电脑端启动中控，通过 SSH 连接机器人。

  2. 未编号的舵机，一次只接一颗

    未编号或可能重号的舵机须逐颗连接，避免同 ID 冲突。已经确认编号不同的舵机可以串联。

  3. 扫描 → 选择舵机 → 保存目标编号

    进入“舵机编号”，手动扫描总线。核对实际位置和对应关节后保存；选择已占用编号时，按界面提示完成交换。

  4. 接回整链核对，再做关节标定

    全部逐颗编号完成后串联扫描核对。单颗中位校准把当前位置设为 2048，之后须重新标定该关节。

What's new

V302：编号更顺手，标定更清晰。

  • 改号复用有效扫描。先手动扫描，再选择舵机；普通改号减少重复全扫描，保留身份核对、目标编号检查与写后读回。
  • 中位校准减少重复等待。复用监测与维护通信会话，按实际反馈确认完成，保留卸力、偏移与回锁核对。
  • 编号与硬件测试进入检查优化。同一连接与所有权、状态未变化时短时复用检查结果；接线、服务占用或组件状态变化后重新检查。
  • 恢复完整 3D 参考工具。标定与运动页可查看实测、零位、HOME 和关节正／负方向，修复左右标签及左下角文字重叠。参考切换只改变显示。
  • IMU 与关节曲线并排。姿态仪与曲线双列显示，切换工作模式后继续使用原有数据源。
  • 直接复用 control.102。原生固件、原有按键和 11 个 ONNX 模型保持不变；已有 R2 / control.102 只更换中控。中文 AI、摄像头和已有动作继续保留。
  • 保留累计修复。缺设备时可返回测试或编号，SSH 与机器人服务状态分开，操作结果在原位置显示。

Get started

完整解压，直接启动。

Windows 运行 start.cmd；macOS / Linux 运行 bash start.command。浏览器打开 http://127.0.0.1:8090，填写自己的 ZERO 地址和 SSH 登录信息。
