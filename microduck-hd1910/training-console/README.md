# 🧠 Microduck Training Studio · R1.5.27

独立的中文训练中控，用于组织训练任务、管理队列、查看奖励曲线与日志、评估物理仿真、导出 ONNX 和完整模型包。

**当前配套：Microduck 官方 0.15.1 · 官方骨架 + 飞特 HD1910 · 14 类动作、35 种任务配方。**

[⬇️ 下载完整训练中控 R1.5.27](https://github.com/kissqy/Microduck-kissqy/raw/refs/heads/main/release-assets/Microduck-Training-Studio-R1.5.27.zip) · [详细训练规则](README.zh-CN.md) · [项目首页](../../README.md)

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 动作与任务配方 | 选择行走、起身、坐站、联合训练、捡取、踢球、前滚翻及轮滑任务。 |
| 训练队列 | 给每项任务保存参数，按顺序执行，查看任务状态和完成情况。 |
| 训练监控 | 查看奖励曲线、进度、采样速度、训练日志和保存的检查点。 |
| 物理仿真 | 查看初始模型、运行所选 PT／ONNX 策略，使用仿真遥控和姿态重置。 |
| 模型导出 | 导出 ONNX 与完整模型包，保留训练和部署所需信息。 |
| 本机标定 | 导入标定文件、中控录制，或通过 SSH 从 ZERO 获取当前标定。 |
| SSH 训练服务器 | 在电脑上操作页面，在 Linux GPU 服务器上训练、评估和保存成果。 |

## 下载与启动

完整解压上方运行 ZIP。打开中控页面的电脑需要 **Python 3.10 或以上**；Windows 安装 Python 后需让 `py` 或 `python` 命令可用。

| 电脑系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start-training.cmd`。 |
| macOS / Linux | 在本目录执行 `bash start-training.command`。 |
| 直接运行 Python | 在本目录执行 `python3 training_console.py --open`。 |

启动后访问 **http://127.0.0.1:8092**，保持启动窗口运行。本目录源码使用同样的启动入口。

中控页面可以独立使用；训练和仿真在所选择的执行端运行。实际训练环境使用 **Linux / WSL2 + NVIDIA GPU**，按页面流程准备冻结版本的训练引擎和依赖。训练本身不要求连接 ZERO，读取实机标定时才需要连接机器人。

## 第一次训练

1. **选择执行位置。** 在“训练位置”选择“本机 / WSL”或“SSH 服务器”。本机使用已有 Linux / WSL 环境；远端填写服务器地址、用户名、SSH 端口、登录方式和工作目录，首次使用点击“部署并准备环境”。
2. **完成首次环境准备。** 固定版本训练引擎和依赖在第一次准备时下载，后续复用已有环境和检测缓存。
3. **准备标定。** 使用本机标定区导入文件、中控录制，或“从 ZERO 获取”，核对这次训练使用的机器和装配数据。
4. **选择任务。** 选择动作、地形及齿隙配方，填写并行环境数、实际训练轮数和运行名称。需要续训或联合训练时，再选择相应检查点或教师。
5. **加入队列。** 点击“＋ 加入队列”。每项任务保存加入时的参数和标定；之后修改页面参数，不会改写已经加入的任务。
6. **开始训练。** 点击“开始训练 ▶”，通过曲线、日志和任务状态查看进度。需要结束训练时，使用页面“停止训练”。
7. **查看模型。** 检查点保存后，在“模型与验证”选择模型，点击“查看所选策略”评估仿真表现。
8. **导出成果。** 使用“导出 ONNX”生成部署模型及完整模型包，再按机器人中控支持的模型类型导入安装。

首次使用先跑通当前任务的默认配方，再一次只调整一个变量。当前新任务默认 P=5、动作系数=1.0；具体训练与部署规则见[详细说明](README.zh-CN.md#当前训练与模型规则)。

## 仿真与模型文件怎么用

| 文件或操作 | 用途 |
| --- | --- |
| PT 检查点 | 继续训练、选择教师，或评估保存时的策略。 |
| ONNX | 运行模型推理、进行相应仿真评估及实机部署。 |
| 完整模型 ZIP | 携带模型及训练、部署信息，便于传输和导入；导出后保留完整包。 |
| 查看初始模型 | 查看当前任务的机器人模型和初始状态。 |
| 查看所选策略 | 运行已选择的模型检查点或 ONNX。 |
| 自动查看新检查点（周期评估） | 随新检查点保存，更新策略评估预览。 |

训练监控区显示正在训练的进度；仿真区评估所选的已保存模型。需要比较训练过程中不同阶段的动作时，可以使用周期评估或手动选择检查点。

## 本机与服务器上的任务

- **本机 / WSL：** 训练记录和模型保存在本机对应的训练目录，页面会显示实际输出路径。关闭网页不等于停止训练，结束任务使用“停止训练”。
- **SSH 服务器：** 队列、训练、评估和成果保存在服务器工作目录；模型可通过页面上传和下载。断开 SSH 或关闭电脑端中控后，服务器上的训练与队列继续运行。
- **服务器重启后：** 重新连接，并从已经保存的检查点继续训练。
