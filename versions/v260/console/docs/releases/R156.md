# Microduck R17 v1.0.156

本版只修正电脑中控的退出与子进程回收。中控为 `1.0.156`，随包固件归档与 v155 逐字节相同，仍为 `1fa8438-feetech-ft6-control.34`；已经安装该固件无需再刷。

## 退出与旧目录占用

Windows `start.cmd` 先切换到系统临时目录，再以绝对路径启动中控；本次中控发起的 SSH 子进程也默认使用临时工作目录，避免把旧解压目录作为持续工作目录。Windows Job 只拥有本次子进程及其后代，已归属的子树随中控 Job 句柄关闭由系统回收，不查杀其他 SSH、Python 或浏览器。

正常 Ctrl+C 退出逐项关闭连接、子进程、管道和日志；一项清理失败仍继续其他清理。断开／换目标在连接锁外等待旧线程结束，并永久关闭旧传输，避免退出或重连期间重新建立旧连接。机制由 [连接设计](../../../docs/design/r17-connection-design.md#process-ownership-and-exit-v10156) 管理。

关闭浏览器标签不是退出 Python 中控脚本。正常更换目录时，请在启动终端按 Ctrl+C 并等待脚本退出。本版不会自动发现或结束旧版已遗留进程。

## 保留的状态

登录地址与 Windows DPAPI 保护的密码继续保存在 AppData；文件仅在读写时打开，不常驻占用解压目录。原连接便利、HOME、手柄、标定、方向显示和模型保持。本版没有修改关节方向：页面继续显示本机保存值，−1 仍表示反向。

机器人原生代码、50 Hz 控制循环和完整随包固件不变，没有新增轮询或恢复循环。

## 使用与验证范围

退出旧中控后，完整解压并启动本版，核对中控 `1.0.156`。已运行 `control.34` 的机器人无需重新安装；较旧设备可继续使用同一随包固件更新。

回归与归档一致性的准确结果见随包清单及源码验证记录。Windows 真机终端关闭与强退尚未实测；保证范围是已归属 Job 的子进程树，不声称覆盖创建暂停进程至加入 Job 之间的极小强杀窗口。
