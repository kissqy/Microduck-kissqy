# Microduck Training Studio R1.5.27

Независимая Training Studio для **прошивки Microduck 0.15.1, официального корпуса + HD1910**. Сейчас предоставляет **14 категорий действий и 35 конфигураций задач**: обычную ходьбу, восстановление, посадку / вставание, совместное обучение, подбор, удары, кувырки вперёд и шесть категорий действий на роликах.

- **Консоль:** <http://127.0.0.1:8092>
- **Проект:** <https://github.com/kissqy/Microduck-kissqy>, ссылка вверху страницы.
- **Среда:** локальная Windows / WSL или SSH-сервер обучения. Обучение не требует Radxa ZERO; подключайтесь только для получения текущей калибровки суставов либо импортируйте файл калибровки.

<a id="启动与训练"></a>
<a id="startup-and-training"></a>
## Запуск и обучение

1. Полностью распакуйте пакет. В Windows запустите `start-training.cmd`; в Linux — `start-training.command`, затем откройте адрес консоли. Окно запуска показывает только версию, адрес консоли и адрес проекта.
2. При первом использовании один раз подготовьте обучающий компьютер по подсказкам страницы. Последующие сеансы используют общий кеш обнаружения. Изменение задачи или открытие страницы автоматически не устанавливает зависимости и не запускает обучение.
3. Выберите действие, число параллельных сред, итераций, модель или контрольную точку учителя и подтвердите параметры. **Перед запуском обучения добавьте задачу в очередь.**
4. Следите за очередью, кривыми награды, журналами и симуляцией. Сохранённые контрольные точки можно использовать для продолжения обучения, оценивать как PT / ONNX или экспортировать полными пакетами.

Обучение, история и модели хранятся в каталоге данных хоста выполнения. Модели и записи текущих 35 задач остаются в существующих каталогах обучения. Локальные записи удалённых задач больше не сохраняются. Старые PT / ONNX на удалённых серверах настольная консоль напрямую не очищает. Используйте согласованные полные версии серверной части и страницы.

## Текущие правила обучения и моделей

| Пункт | Правило |
| --- | --- |
| Прошивка и интерфейс политики | Microduck `0.15.1`; модели соблюдают свои контракты наблюдений, действий и порядка суставов. |
| Динамика робота | Официальный корпус + адаптация HD1910; существующие BAM M6 и конфигурация масс зафиксированы. |
| Умолчания новых задач | Сервоприводы **P=5**, масштаб действий при обучении **1.0**, без дополнительной EMA-фильтрации целей головы / ног. |
| Программа обучения | Зарегистрированные награды, возмущения, местность, люфт и программа обучения сохранены; соответствующий прогресс корректируется по объёму выборки с учётом параллелизма. |
| Контрольные точки | Интервал по умолчанию: 1,000 фактических итераций обучения. Оценка / экспорт исторических моделей следует сохранённой исходной конфигурации. |
| Экспорт | Сохраняет модель, исходные сведения об обучении, параметры развёртывания и необходимую информацию совместимости. Настройки развёртывания не переобучают модель. |

**Действия на роликах:** официальные ходьба на роликах и приседание используют масштаб действий обучения PPO **1.0**. Пресеты развёртывания соответствующих официально выпущенных моделей: множитель инференса **0.8**, фильтр головы **0.5**, фильтр ног **0.7**. Вход X в симуляции ходьбы на роликах — **команда разгона / скольжения / торможения** (от −0.5 до +0.6), а не обычная скорость ходьбы. Эта прямолинейная задача не передаёт команды бокового движения или поворота. Swizzle, спуск, восстановление на роликах и вращение следуют собственным правилам обучения / экспорта; не применяйте к ним неподтверждённые множители выпущенных моделей.
