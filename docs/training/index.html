首次连接 / 登录说明

服务器使用 Linux + NVIDIA GPU，需要 Python 3.10+、git 和 python3-venv。选择“密码登录”后填写服务器用户名和密码即可；首次连接显示服务器指纹，核对后确认并继续。选择密钥登录时使用系统OpenSSH或ssh-agent，加密密钥需先加入ssh-agent。

ssh -p 22 ubuntu@服务器IP

密码不写入连接配置，也不会在状态和日志中回显；页面刷新后本次连接仍可使用，关闭并重启中控需要再次输入。密钥路径仅保存于本机。首次部署会上传本版中控、初始化本机机器人物理配方，并准备固定版本训练环境。已有服务器配方和训练记录会保留。

上传原中控导出的完整ZIP；支持当前0.15.1训练源的独立动作模型，最多30MB。
