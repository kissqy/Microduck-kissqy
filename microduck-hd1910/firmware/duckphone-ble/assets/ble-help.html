连不上怎么办

这个 App 只用手机蓝牙连机器人。机器人自己的 Wi-Fi 只影响网页版和 SSH，不影响驾驶，不用把手机连到同一个路由器。

先试这三步
  1. 手机蓝牙已开，App 有「附近的设备」权限。
  2. 机器人在 2 米内、已上电；连接页点「重新扫描」能看到 duck-…。
  3. 选中它点「连接」；还在转圈就回连接页再点一次。

1. 先看「未连接」浮层写了什么

  • 设备：上次连的是哪台。多台机器人时先确认没连错。
  • 上次连接：最后正常的时间、策略和电量；时间很旧说明断了一阵。
  • 断开原因：
    • 「蓝牙连接中断」= 机器人断电、走远、或机器人上的蓝牙服务停了；
    • 「PIN 不正确」= 去连接页重新输入六位 PIN；
    • 「固件是 API …」= 机器人固件太旧，等新固件部署后再连。

2. 扫不到机器人

  • 机器人已上电，离手机 2 米内；金属、水、人体都会挡 2.4 GHz。
  • 机器人上的蓝牙服务在跑：systemctl is-active btd 应为 active。
  • 手机蓝牙里如果还残留旧的配对记录，先「忽略此设备」再扫描。
  • 扫描一次约 5–10 秒；扫完没结果就点「重新扫描」，别一直等。

3. 提示 PIN 不正确

  • 默认 PIN 是 000000；改过就用新的六位数字。
  • 连续错 5 次会锁 60 秒，等提示的倒计时结束再试。
  • 忘记 PIN 时在机器人上执行 robotctl system set-pin 重设。

4. 一直在「连接中…」或反复断开

  • 退回连接页再点「连接」——会重开会话、重新认证和订阅。
  • 页面显示「已连接」但数据不动：多半是机器人端 btd 重启过。 App 会在连续 5 次健康检查超时后自动断开重连，等 15–30 秒即可。
  • 切到别的页面再回来时，会先显示上次的数据，几秒内自动转成实时值，这是正常的。
  • 仍不行就按第 7 步重启机器人端服务。

5. 能连上但机器人不动

  • 手柄服务在抢控制权。顶部黄条会提示，点「详情」可以直接停掉它。
  • 策略没接管：先点「站立」，等机身立正（倾角 ≤10°），再点「接管」。
  • 看「状态」里的控制环频率，低于 45 Hz 说明板子忙或散热有问题。
  • 看「未执行」提示里的原因：指令超时 = 摇杆没按住或蓝牙链路抖动。

6. 蓝牙和「机器人 Wi-Fi」是什么关系

  • 控制、状态、配网全走蓝牙，手机连不连 Wi-Fi 都能开。
  • 顶部「机器人 Wi-Fi」那一格只是显示机器人自己有没有连上路由器； 它断了不影响蓝牙驾驶，只影响网页版 :8001 和 SSH。
  • 点那一格进网络页，是给机器人换 Wi-Fi 用的，不是在配手机。

7. 机器人端检查与重启

systemctl status robotd btd
sudo systemctl restart btd     # 只重启蓝牙，不影响姿态
sudo systemctl restart robotd  # 会重新回 HOME，机器人先扶稳

物理 HUB 上的电源开关是最后手段。

8. 还不行

  • 从最近任务里划掉 App 再打开，让蓝牙栈重新初始化。
  • 手机关一次再开蓝牙（或开飞行模式 10 秒）。
  • 把上面的现象和「设备 / 上次连接 / 断开原因」三行一起记下来，方便排查。
