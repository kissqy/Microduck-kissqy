# R1.5.16 密码SSH登录补充

1. 关闭旧Windows中控，解压本修正版完整包并启动，WSL和服务器后台训练不需要重启。服务版本仍为R1.5.16，可继续连接已部署的同版服务。
2. 在训练位置选择SSH服务器，填写IP/主机名、用户名、端口、工作目录；登录方式选择密码登录，输入实际服务器SSH密码。
3. 首次选择密码登录时点击部署或连接，中控在自己的数据目录准备paramiko密码SSH组件，不安装到训练环境、不修改服务器密码或认证配置。需要本机Python有pip并能下载软件包；后续复用组件。密钥模式无需这个组件。
4. 未保存的服务器SSH主机指纹会显示在页面，核对后点击确认指纹并继续。主机指纹变化会拒绝连接，不静默替换原记录；已有系统known_hosts也会用于校验。主机身份确认前不会发送密码。
5. 新服务器点击部署并准备环境，已有同版服务点击连接/重连。登录、上传、主API和画面转发使用密码认证后的同一SSH连接，后续操作无需重复输入密码。
6. 密码不会保存在connection.json或返回状态、日志，也不会作为进程参数传递；输入框提交后清空。中控运行期间在内存按服务器/用户名/端口保留，页面刷新可继续使用，完全重启中控后需再输入。
7. 导出仍选择PT后点击导出ONNX，再点击下载模型包；服务器端导出，ZIP经SSH传回本机。不需要手工复制路径或改为密钥认证。

WSL测试继续使用原专用密钥通道；原保存的密钥连接不会自动改成密码。关闭/断开中控只关闭本机隧道和连接，服务器后台队列和训练继续。密码模式的转发在中控进程内运行，不额外启动Windows ssh.exe子进程。

本次未改训练动作系数、滤波、P、物理参数、冻结源码和老师合同。现有WSL nvidia-smi路径修复保留。

验证：密码协议服务验证主机身份确认前不发送密码、正确/错误密码、20MB部署、API、模型上传、ZIP传输、等待队列、断线重连同一后台、独立画面端口、本机监听清理及配置/状态不回显密码；CPU和界面处理器回归通过。未连接用户真实首尔服务器，未启动GPU训练。

实现依据：[Paramiko SSHClient](https://docs.paramiko.org/en/stable/api/client.html) 和 [Transport](https://docs.paramiko.org/en/stable/api/transport.html)。
