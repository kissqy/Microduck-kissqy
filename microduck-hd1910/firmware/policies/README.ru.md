# Базовая версия политик — R17 v1.0.146 / официальная 0.15.1

<a id="policy-baseline--r17-v10146--official-0151"></a>
Эта историческая базовая версия использует одну модель Walk: совместную политику ходьбы / восстановления после падения на 9600 итераций с базовым масштабом 0.9, фильтром головы 0.5 и ног 0.7. Старая модель ходьбы на 14000 итераций удалена из прошивки и сохранена только в `test-data/walk-teacher14000` для численной регрессионной проверки исходников. Ручное восстановление LB сохраняет учителя на 11000 итераций (базовый масштаб 1.0, голова / ноги без фильтрации), автоматический Stand не назначен; посадка / вставание, подбор и кувырок вперёд сохранены.

Исходные записи обучения и независимые рабочие настройки поясняются в [проектировании robotd](../docs/design/robotd-design.ru.md). Импорт, назначение уникального слота, очистка выведенных моделей и сохранение при обновлении описаны в [проектировании настроек](../docs/design/r17-settings-design.ru.md). Назначения V164, названные текущими в этом историческом документе, см. в [руководстве консоли](../console/USER-GUIDE.ru.md).
