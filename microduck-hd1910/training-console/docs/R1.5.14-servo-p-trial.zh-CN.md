# P=3行走试训与输出限制

先做一组只改变P的试训，判断纠偏过强是否改善。

| 项目 | 本次设置 |
|---|---|
| 舵机P / Servo P | 新建训练默认3，可修改为1～32的整数 |
| P=2.69 | 同电压、小误差、近静止、未饱和、未扣摩擦的BAM估算；实机无法原样写入 |
| P=3模型纠偏斜率 | 约为XL330训练P=200的1.116倍；P=5约1.860倍 |
| 动作系数 | 沿用页面选择；复现改善明显的那次实验时选0.7 |
| 头颈／腿部滤波 | 沿用页面选择；对应上一模型为0.5／0.7 |
| 最大PWM | 本次保留HD1910模型0.97 |
| 模型限流 | 本次保留原来的未建模状态；不代表实机没有电流保护 |
| 质量、齿隙、标定、摩擦随机化 | 沿用当前机器人配方和所选任务 |

## 使用步骤

1. 解压R1.5.14，用原来的启动脚本打开。已有训练记录仍从同一应用数据目录读取。
2. 选择行走老师和与上一轮相同的地形／齿隙选项；开始方式选新建训练。
3. 确认舵机P为3，动作系数和滤波与上一轮相同。其他实验条件尽量相同。
4. 加入队列，再开始训练。队列保存加入时的P；后续修改页面不影响已经加入的项目。
5. 日志中应出现“[训练舵机P / Servo P] 实际执行器P=3”。实际训练读回中的执行器kp_fw也应为3。
6. 模型仿真、导出使用源训练记录的P，导出合同hardware_command.firmware_kp_raw与训练执行器kp_fw均为3。
7. 使用R17 v1.0.129部署时，先卸力，将P=3模型导入走路槽，重启固件，再显式启用运动。该固件在进程初始化时读取走路模型的硬件P，启用时写入并读回校验；仅切换动作不会重新读取P。

旧P=5模型进入仿真、续训和导出时仍使用其原P。续训不将旧权重重新标记为P=3；需要改变训练P时选择新建训练。联合任务的两位老师与学生也需要相同的P。

## PWM=0.681应该怎样改

0.681是同7.4V模型、近静止时，对齐XL330静止毛扭矩上界的候选占空比。它限制大误差时的最大驱动输出，不改变小误差的P斜率，也不改变目标角度映射。它不是厂家推荐设置，也不是整段步态的等效参数。

训练端的max_pwm来自BAM控制器类，不是hd1910_m6.json中的辨识字段。实现时应在实际执行器构建阶段设置max_pwm，并验证实际控制输出确实限幅，同时在训练快照中记录读回。实机端需要按各颗HD1910的实际固件版本和模式，确认对应的输出限制寄存器及比例，再配套写入并读回。历史截图中一颗舵机版本为3.46、模式为4，不能据此认定15颗今天完全一致。当前1.0.129没有根据模型合同写入PWM上限。

不能将动作系数改成0.681来代替PWM上限，也不能只修改仿真就宣称实机输出上限已经对齐。本版没有加入未经实机映射确认的PWM修改。

## 等效1.027A应该怎样改

1.027A根据HD1910的辨识扭矩常数估算，用于接近XL330模型1.75A对应的静止毛扭矩上界。它是每颗舵机的电机等效电流候选，不是机器人总供电电流，也不能直接当作飞特寄存器原始数字写入。

若采用限流方案，训练端必须实现当前HD1910控制器实际消费的电流限制；仅增加max_current字段或改显示没有作用。实机端还需确认电流单位、限流寄存器，以及模式4位置PD下是否持续生效。原截图中目标电流44和保护电流28有原始数值，但本机电流单位仍未确认。

PWM上限和电流上限是两种限制机制：在特定静止工况可接近同一扭矩上界，随电压和速度变化时不等价。本次先保留两项原配置，只验证P的影响。

## 官方D/I

官方XL330驱动的set_gain明确写入Position I Gain=0、Position D Gain=0；P使用官方增益配置。地址分别为82、80、84。

我们R17 v1.0.129的飞特适配：头腿P取走路模型合同，D固定20，I不写；嘴巴P固定10、D固定20。本次P试训未修改D/I。不同舵机的D数字不能直接互相照抄；还需要核对HD1910 BAM辨识时的D工况，才能判断是否包含当前D=20的效果。
