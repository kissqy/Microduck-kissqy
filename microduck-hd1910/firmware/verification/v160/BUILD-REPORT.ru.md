Проверка компиляции и упаковки Microduck R17 V160 / control.37

Выполнена реальная компиляция ARM64. Версии: консоль 1.0.160, прошивка control.37, официальная система 0.15.1.
Полная база: указанный пользователем Microduck-Console-R17-V159.zip.
Сохранены запрошенные пользователем изменения калибровки V159, исправление пароля SSH, ссылки GitHub в веб-интерфейсе / CMD и исходные модели.
robotd, padd, robotctl и mediad V159 совпадают с 157-Fix10; исходные программы — control.36.
Логика геймпада V160 собрана по исходникам V160 без повторных изменений.

Калибровка следует V159, без отката к Fix10; файлы калибровки и контракты моделей побайтово совпадают с V159.
Восстановлена база упаковки, ошибочно откаченная помощником; уже скомпилированные robotd/padd control.37 сохранили те же байты.

Текущий объём тестов: ядро управления — 136 модульных, протокол IPC — 53 модульных, padd — 33 модульных, ролики robotd — 3; всего 225 пройдено, 0 ошибок. ARM64 robotd успешно загрузил три исходные роликовые ONNX в QEMU. Этот объём не включает все модульные тесты robotd и интеграционные тесты служб.

Историческая диагностика всего проекта: 472 пройдено, 31 ошибка, 10 игнорировано; исходные журналы сохранены.
14 тестов ограничены Unix socket среды; 10 зависят от отменённой конфигурации LB/stand_test, 4 ожидают старые этапы запуска / порядок сбора, 3 теста режима используют прежние ожидания отсутствия контроллера / повторной очереди. Эти ошибки не переписаны в успешные результаты.

Проверка продукта: ZIP CRC, SHA256 всего манифеста и реальный импорт консолью пройдены.
124 исходных файла прошивки совпадают с V159, включая указанную пользователем калибровку, исходные модели / контракты, mediad, мост ввода и установку.
158 исходных файлов консоли совпадают с V159, включая исправление SSH в service_control.py и ссылки на исходники в веб-интерфейсе / CMD.
Добавлены три роликовые модели, заменены новые robotd/padd и соответствующие записи версий / установки. Неактивные копии в исходном experiments/roller заменены официально поставляемыми моделями.

Инструменты компиляции: Rust 1.99.0, Zig 0.15.1, cargo-zigbuild 0.23.4.
Цель: aarch64-unknown-linux-gnu.2.31; максимальный glibc ABI новых программ — 2.30.
Проверка на физическом Zero пока не завершена.
