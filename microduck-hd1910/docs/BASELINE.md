## 本次交付有什么

- `firmware/`：最新固件工作区、设备服务、飞特翻译层、打包/安装脚本、手柄桥源码、HAT/IMU源码和原有验证记录。
- `firmware/console/`：与独立机器人中控包相同的 Python、网页、启动入口、3D资源及升级载荷；这里是机器人中控的唯一源码位置。
- `training-console/`：完整自有训练中控源码、任务配置、远程执行适配、测试和原许可。训练引擎及 Python/GPU 依赖首次准备时联网取得，不是全离线环境快照。
- 整套交付包的 `release-assets/`：三份 Public 运行/升级 ZIP 与 SHA256。每份加了授权/来源说明，固件 tar 载荷和已编译程序字节不变。

官方主仓其他服务（例如 mediad/configd/updaterd）的源码保留在固件工作区；当前 R17 编译升级包的主载荷是 robotd、robotctl、padd、sounds 和手柄桥，不冒充整盘 Linux 镜像。
