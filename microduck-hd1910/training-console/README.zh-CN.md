# Microduck Training Studio R1.5.27

独立训练中控，面向 **Microduck 固件 0.15.1、官方骨架 + HD1910**。当前提供 **14 类动作、35 种训练任务配方**，包括普通行走、起身、坐站、联合训练、捡取、踢球、前滚翻及六类轮滑动作。

- **中控地址：** <http://127.0.0.1:8092>
- **开源项目：** <https://github.com/kissqy/Microduck-kissqy>（网页顶部有直接入口）
- **运行环境：** 本机 Windows/WSL，或通过 SSH 连接训练服务器。训练不要求连接 Radxa ZERO；需要当前关节标定时才读取机器人或导入标定文件。

## 启动与训练

1. 完整解压安装包。Windows 运行 `start-training.cmd`；Linux 运行 `start-training.command`，在浏览器打开中控地址。启动窗口仅显示版本、中控网址和开源地址。
2. 首次使用训练电脑时按网页提示完成一次环境准备；后续共用检测缓存。切换任务或进入网页不会自动安装环境或启动训练。
3. 选择动作、并行环境、训练轮数、模型或教师检查点，确认本次训练参数；**先加入队列，再点击开始训练**。
4. 通过队列、奖励曲线、日志和仿真查看训练进度；保存检查点后可以继续训练、评估 PT / ONNX 或导出完整模型包。

训练过程、历史记录与模型保存在运行机器对应的数据目录。现行 35 种任务的模型与记录保持在原训练目录；已停用任务的本地记录不再保留。远端训练服务器上的旧 PT/ONNX 不由桌面中控直接清理。训练后台与网页请使用同一完整版本。

## 当前训练与模型规则

| 项目 | 当前规则 |
|---|---|
| 固件与策略接口 | Microduck `0.15.1`，模型遵循对应观测、动作及关节顺序合同 |
| 机器人动力学 | 官方骨架 + HD1910 适配；既有 BAM M6 和质量配置保持冻结 |
| 新建任务默认值 | 舵机 **P=5**；训练动作系数 **1.0**；不额外施加头、腿目标 EMA 滤波 |
| 训练课程 | 沿用随任务注册的奖励、扰动、地形、齿隙和课程；并行数按采样量换算相关课程进度 |
| 检查点 | 默认每 1000 实际训练轮保存；评估和导出历史模型时遵循其保存的原始配置 |
| 模型导出 | 同时记录模型、原训练信息、部署参数及必要的兼容性信息；部署参数不等于重新训练 |

**轮滑动作：** 官方轮滑行走和轮滑蹲下的 PPO 训练动作系数均为 **1.0**；与官方已发布模型对应的部署预设为推理倍率 **0.8**、头部滤波 **0.5**、腿部滤波 **0.7**。轮滑行走仿真遥控的 X 轴是**推进/滑行/制动控制值**（−0.5～+0.6），不是普通行走速度；这项直线任务不发送横移与转向命令。对称蹬滑、下坡、轮滑起身和原地旋转遵循各自训练与导出规则，不套用未确认的成品倍率。
