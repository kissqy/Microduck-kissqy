# Изменения R17 v1.0.137 / официальной версии 0.15.1

<a id="r17-v10137--official-0151-changes"></a>
Дополнительные изменения upstream-исходников относительно v1.0.136:

- `duck-control/src/deployment.rs`: принимает контракт пересечённой местности, явно отключающий фильтрацию; требует alpha головы / ног 1. Сохраняет флаг пропуска фильтра для этой модели без изменения глобальных параметров.
- `robotd/src/control.rs`: обходит исходную низкочастотную фильтрацию, когда активная модель явно требует пропуск фильтра, восстанавливает исходные параметры после выхода из неё и предоставляет фактические настройки активной фильтрации.
- `robotd/src/main.rs`: добавляет считывание `active_target_filters` в данные шины; остальные пути управления и телеметрии сохранены.
- `robotd/src/feetech_commissioning.rs`: обновляет идентификатор сборки до control.21.

LB использует существующий официальный интерфейс именованных навыков с учителем восстановления на 11000 итераций и базовым масштабом 1.0. Импортёр Python принимает тот же контракт. Консоль показывает фактическую фильтрацию модели, не добавляя переключатель фильтра. Исходные контракты моделей и ONNX-файлы не изменены.

Официальное планирование навыков, UART / HAT, преобразование единиц калибровки, отмена HOME, звук и мост физического геймпада перенесены из v136. Глобальные алгоритмы фильтрации и конфигурация не меняются; официальная компенсация напряжения по-прежнему влияет на фактическое масштабирование. Пересобран только robotd; остальные бинарные файлы повторно использованы из v136. Предыдущие изменения и временные испытания сервоприводов описаны в [истории R17](R17-CHANGES.ru.md) и [проектировании настроек](docs/design/r17-settings-design.ru.md). Полные различия файлов — в `R17-SOURCE-MANIFEST.json`.
