# 🎮 Microduck Robot Console · R17 V167

<a id="-microduck-机器人中控--r17-v167"></a>
Консоль с китайским интерфейсом для настоящего робота-утки: просмотр позы и обратной связи устройств, калибровка суставов и IMU, управление геймпадом, работа с моделями движения и обслуживание прошивки.

**Текущая конфигурация: Radxa ZERO 3W · Feetech HD1910 · официальный Microduck 0.15.1 · прошивка control.43.**

[⬇️ Скачать полную консоль V167](https://github.com/kissqy/Microduck-kissqy/raw/refs/heads/main/release-assets/Microduck-Console-R17-V167.zip) · [Подробное руководство и управление геймпадом](USER-GUIDE.ru.md) · [Главная страница проекта](../../../README.ru.md)

<a id="能做什么"></a>
<a id="features"></a>
## Возможности

| Возможность | Назначение |
| --- | --- |
| 3D и обратная связь устройств в реальном времени | Поза робота, данные 15 сервоприводов, графики суставов и ориентация корпуса по IMU. |
| Рабочая область суставов | Проверка локальных нулей, направлений, пределов и установки IMU; калибровка после сборки. |
| Управление геймпадом | Ходьба, посадка / вставание, подбор, кувырок, удары и ролики с физического геймпада; на странице есть китайские пояснения кнопок. |
| Управление моделями | Просмотр установленных моделей и параметров развёртывания; импорт самостоятельно обученных моделей поддерживаемых типов. |
| Камера | Подключение к камере головы, запуск и завершение видеосеансов по запросу. |
| Обслуживание системы | Просмотр состояния ZERO, изменение громкости, установка комплектной прошивки, перезагрузка и выключение. |
| Запись и воспроизведение | Экспорт наблюдений и просмотр отладочных сеансов на графиках суставов и в 3D. |

Прошивка V167 содержит **10 моделей движения: 6 обычных и 4 роликовых**. Назначения кнопок, смена режимов, условия действий и параметры развёртывания определены в [подробном руководстве](USER-GUIDE.ru.md).

## Скачивание и запуск

Полностью распакуйте указанный выше ZIP-пакет запуска и откройте папку с `start.cmd`. На компьютере нужны Python 3 и команда `ssh` из OpenSSH; рекомендуется Python 3.10 или новее.

| Система | Запуск |
| --- | --- |
| Windows | Дважды нажмите `start.cmd`; скрипт использует установленный Python. |
| macOS / Linux | Выполните `bash start.command` в этом каталоге. |
| Прямой запуск Python | Выполните здесь `python3 console.py --dashboard --feetech --open`. |

Браузер откроет консоль; адрес **http://127.0.0.1:8090** можно открыть и вручную. Оставьте терминал запуска работающим.

Исходники в этом каталоге используют те же программы запуска. Для обычного использования скачайте полный ZIP-пакет, содержащий ресурсы страниц и пакет прошивки.

<a id="第一次连接鸭鸭"></a>
<a id="first-connection"></a>
## Первое подключение

1. Подключите компьютер и ZERO к одной локальной сети. Дождитесь загрузки ZERO и узнайте его IP-адрес.
2. Заполните **SSH 地址** («Адрес SSH») в формате `username@robot-IP`, например `radxa@your-robot-IP`.
3. Введите **SSH / sudo 密码** («Пароль SSH / sudo») и нажмите **连接** («Подключиться»). Если учётные данные сохранены или настроена аутентификация ключом, следуйте подсказкам страницы.
4. Дождитесь запуска служб робота **1/4–4/4**, затем проверьте обратную связь, состояние IMU и загрузку моделей.
5. После первой сборки или замены сервоприводов проверьте свои нули, направления, пределы и IMU в рабочей области суставов, затем выполните HOME.
6. После завершения HOME включите политику движения и используйте геймпад. Ввод физического геймпада имеет приоритет перед вводом страницы.

В опубликованном интегрированном образе службы робота уже установлены. Для установки или обновления служб на другой существующей системе используйте **系统维护 → 随包固件** («Обслуживание системы → Комплектная прошивка»). Если ZERO уже работает на control.43, при обновлении только консоли на компьютере следуйте руководству соответствующей версии.

<a id="日常操作"></a>
<a id="daily-use"></a>
## Повседневное использование

- **Ходьба и действия:** завершите HOME, включите политику, затем используйте стики и кнопки действий. Поведение Start, посадки / вставания, ударов и кувырков см. в [назначениях геймпада](USER-GUIDE.ru.md#other-buttons).
- **Ролики:** переключайте режимы ходьбы / роликов и роликовые действия физическим геймпадом; см. [управление роликами](USER-GUIDE.ru.md#physical-gamepad-roller-controls).
- **Калибровка:** используйте фактические данные сборки именно этого робота; см. [калибровку и настройки](USER-GUIDE.ru.md#calibration-and-settings).
- **Завершение:** снимите крутящий момент через страницу или геймпад. Перед закрытием процесса консоли нажмите Ctrl+C в терминале запуска и дождитесь выхода.
