# 🔧 装机与使用注意事项

以下为 kissqy 在本项目实机装配和运行中总结的注意事项，记录于 2026-10-22。

## ZERO 使用 5 GHz Wi-Fi

**使用无线手柄时，将 Radxa ZERO 3W 连接到路由器的 5 GHz Wi-Fi。** 这里的“5G Wi-Fi”指 5 GHz 无线局域网频段。

作者实机遇到过：ZERO 使用 2.4 GHz Wi-Fi 时，与手柄的 2.4 GHz 无线通信相互干扰，出现 ZERO 断网、SSH 超时或无法连接。因此，本项目装机和使用时按 **ZERO 连接 5 GHz Wi-Fi** 配置，避免与手柄共用 2.4 GHz 频段。

- 路由器开启 5 GHz 网络；若双频合一不方便确认，分开两个频段的 Wi-Fi 名称，让 ZERO 明确连接 5 GHz。
- 手柄接入后出现断网或 SSH 连不上，先确认 ZERO 实际连接的频段。连接名里有“5G”不等于实际一定连在 5 GHz。
- 可在 ZERO 的终端执行下面的只读命令，查看当前连接（`IN-USE` 列标记为 `*`）的频率：

```bash
nmcli -f IN-USE,SSID,FREQ,SIGNAL device wifi list
```

## 总电源入口并联 1000 µF 电容

**本项目装机时，在整机总进电口的电源正负极之间并联一只 1000 µF 电容。** 作者实机经验是：缺少这只缓冲电容时，舵机全功率输出产生的瞬时负载容易导致 ZERO 重启。

- 电容靠近总进电口安装，连接线尽量短；接在给舵机与 HAT 供电的总电源输入两端。
- 使用有极性电容时，**正极接电源正极，负极接 GND**；断电后接线，避免反接或短路。
- 耐压应高于该输入端的最高工作电压，并留出余量。按本项目约 7.3 V 的供电配置，可选 **16 V 耐压的 1000 µF 电容**；其他供电电压需重新核对。
- 这是总电源输入侧的外接缓冲电容，不是把电源接到 ZERO 的 GPIO 或直接改动其 5 V 电源轨。
- 电容用于缓冲瞬时负载，不能代替足够输出能力的电池、电源、线材和可靠接头。若仍然重启，继续检查负载下的供电压降和接线。
