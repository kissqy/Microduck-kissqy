Workspaces

Four modes, one clear workflow.

Connect to ZERO by SSH, then select the workspace for the operation you need.

01 / TEST

Hardware tests

Inspect IMU orientation, microphone input and speaker sound. Wiring references are available on the test page.

02 / NUMBER

Servo numbering

Scan the bus, inspect actual positions, save joint IDs and perform single-servo midpoint calibration.

03 / CALIBRATE

Joint calibration

Check direction, zero and limits in a dedicated workspace with a larger 3D view. Hardware faults identify the affected device.

04 / MOTION

Robot motion

Gamepad hints, motion controls, joint feedback, curves, camera and ToF, with existing Chinese AI in a dedicated column.

HAT / Servo ID

Number servos through the HAT.

  1. Connect the hardware and SSH

    Follow the test-page wiring reference, supply the HAT and servos, start the desktop console and connect to ZERO.

  2. Connect one unnumbered servo at a time

    Servos with the same or unknown ID must be numbered individually. Verified distinct IDs can be chained.

  3. Scan, select and save

    Enter Servo numbering, scan the bus, check the detected servo and choose its target joint ID. Follow the UI for an occupied-ID swap.

  4. Check the full chain, then calibrate

    After all individual IDs are confirmed, reconnect the chain and scan again. Recalibrate any joint whose midpoint was changed.

What's new

V302: smoother numbering, clearer calibration.

  • Reuse a valid scan for ID changes. Scan manually first; subsequent changes avoid redundant full scans while retaining identity, target-ID and readback checks.
  • Reduce repeated waits for midpoint calibration. Reuse the monitor and maintenance communication session; retain torque-release, offset and EEPROM-lock readbacks.
  • Reuse valid entry checks. Short-lived preflight results are reused only while connection, ownership and service/component state remain unchanged.
  • Complete 3D references. Measured, zero, HOME and positive/negative joint views are available in Calibration and Motion. Reference views change the display only; label overlap is corrected.
  • Side-by-side IMU and joint charts. The two-column layout continues using the existing shared data source.
  • Reuse control.102 unchanged. Native firmware, existing button mappings and all 11 ONNX models are retained. Existing R2 / control.102 users only replace the desktop console.
  • Keep previous fixes. Missing-device recovery, separate SSH/service states and in-place operation feedback remain available, together with existing Chinese AI and camera features.
