# R1.5.6 界面验证

普通训练与网络设置作为完整左列；奖励权重/扰动作为完整右列，顶部对齐。右列奖励滚动不改变左列位置或页面滚动位置。左列不设置内部滚动或固定裁切高度，老师选择展开后由内容决定卡片高度。

真实 Chromium 154 / HTTP 测试结果：

- 3840×2160：行走/起身奖励列表高 639px，完整显示 12 项；联合任务列表高 744px，完整显示 14 项。列表距卡片底部保持 13px，最后一项滚动可达。参数与课程卡片等高。
- 1920 / 1280 / 1024px：奖励区域高 675 / 727 / 675px；参数卡片未超出窗口。390px 下自动上下排列，奖励单独滚动高度 360px。
- 实际展开的下拉菜单使用 `appearance: base-select`，面板 #101719、选中 #222d22、悬停 #25332d，未使用蓝色系统高亮。鼠标选择 ReLU 后读取到实际训练参数 relu；键盘选择 Tanh 后原生 select 值为 tanh。
- 本次 UI 可配合旧 R1.5.5 后台加载，静态覆盖更新测试通过。切换动作未发送环境检查、预检或训练请求；无 JavaScript 错误。
- 原有浏览器工作流验证通过：12 个任务、并行数对应的预算/课程、旧 V2 老师选择、联合启动、仿真与训练并存、即时 BAM 编辑、110 项寄存器搜索。

使用本地测试夹具，未启动 GPU/WSL 训练、未访问机器人。训练参数与模型文件未更改。原有 Windows/WSL 关闭与保活问题不在本次界面修改范围内，训练中保持启动脚本开启。
