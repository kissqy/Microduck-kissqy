# 手机控制 Microduck · 蓝牙版功能清单

> 2026-11-26 · 面向 Android 蓝牙 App
> 来源：duckphone（手机网页控制）+ ducknet（PC 蓝牙配网）+ 新增 BLE 连接/共存能力
> 原则：**原网页版 duckphone 一行不改，继续在局域网 `:8001` 独立运行；蓝牙版是另一个客户端。**
>
> 配套文档：[改造方案](./duckphone-ble-plan.zh-CN.md) · [UI 设计](./duckphone-ble-ui.zh-CN.md) · [实现设计](./duckphone-ble-implementation.zh-CN.md)

## 0. 两版怎么共存

| 问题 | 答案 |
| --- | --- |
| 原网页版还保留吗 | 保留，代码、部署、端口 `:8001`、使用方式都不变 |
| 蓝牙版会改网页版吗 | 不会。蓝牙版是独立 APK，自己的页面与代码 |
| 能同时驾驶吗 | **不建议**。两个客户端都向 robotd 发 `robot.move`，后到的覆盖先到的；App 会提示控制源冲突 |
| 数据共享吗 | 不共享。两台客户端各自保存机器人/PIN/网络配置 |
| 同一个机器人能同时连接吗 | 能。BLE 和 LAN 是两条独立通道；BLE 同时只服务一台手机 |
| 蓝牙和 Wi-Fi 是一回事吗 | **不是**。蓝牙是「手机 ↔ 机器人」，Wi-Fi 是「机器人 ↔ 路由器」；两者互不代表 |
| 网页版坏了怎么办 | 蓝牙版仍可连接、配置网络、看日志、重启，这是 BLE 作为「永久通道」的意义 |

### 0.1 两条完全不同的链路

| 链路 | 连接谁 | 断开后的影响 | UI 位置 |
| --- | --- | --- | --- |
| **手机蓝牙** | 手机 ↔ 机器人 | 无法驾驶/控制；机器人自己的 Wi-Fi 可能仍然在线 | 顶栏「蓝牙」chip、连接页、机器人中心·连接 |
| **机器人 Wi-Fi** | 机器人 ↔ 路由器 | 蓝牙仍可驾驶和配置网络；网页版/SSH 不可达 | 顶栏「Wi-Fi」chip、机器人中心·网络 |

**必须一直说清楚的一句话**：蓝牙连上 ≠ 机器人有网；机器人没网也能用蓝牙驾驶和配置网络。

## 1. 蓝牙连接与设备管理（新增）

| 编号 | 功能 | 首版 | 接口 / 实现 | 说明 |
| --- | --- | --- | --- | --- |
| C1 | 扫描机器人 | ✅ | BLE 扫描，按 Service UUID `6f5d2a10-…` 过滤 | 显示名称、RSSI、广播 IPv4、已保存标记 |
| C2 | 显示全部蓝牙设备 | ✅（开发者） | 扫描时关闭过滤 | 排障用，默认关闭 |
| C3 | 多机器人列表 | ✅ | 本地保存 `serial / name / lastSeen` | 按 SoC 序列号识别，改名不丢 |
| C4 | 上次连接 / 自动连接 | ✅ | 本地偏好 | 打开 App 自动连上次那台；失败回到扫描页 |
| C5 | PIN 输入 | ✅ | `system.authenticate {pin}` | 6 位，出厂 `000000`；按机器人记住 |
| C6 | 连接流程 | ✅ | 连接 → 发现服务 → 读 API → 订阅通知 → 认证 | 分步进度，可取消 |
| C7 | 断开 / 切换机器人 | ✅ | 主动断开 GATT | 切换时回到扫描页 |
| C8 | 自动重连 | ✅ | 指数退避 + 每轮 8 次 | 重连后重新认证、重新订阅；**不重放动作** |
| C9 | 连接状态展示 | ✅ | 本地状态机 | 扫描中 / 连接中 / 认证中 / 已连接 / 重连中 / 离线 |
| C10 | 信号强度 | ✅ | 广播 RSSI / 连接后 RSSI | 4 格信号条 + dBm |
| C11 | 版本握手 | ✅ | GATT 读 API 版本；`API_VERSION >= 42` | 低于要求时明确提示升级固件 |
| C12 | 蓝牙权限 / 开关 | ✅ | Android 12+ 权限、系统设置跳转 | 未授权/未打开蓝牙时有明确引导 |
| C13 | PIN 错误次数 | ✅ | `attempts_remaining` | 显示剩余次数；用尽后会话关闭 |
| C14 | 默认 PIN 警告 | ✅ | 本地判断 + 文案 | 提示先 `robotctl system set-pin` |
| C15 | 链路加密状态 | ✅ | 本地配对/绑定状态 | 未加密时显示「PIN 会明文经过空中」 |
| C16 | 另一台手机占用 | ✅ | `btd` 只服务一个中心；连接失败原因 | 提示「另一台手机已连接」 |
| C17 | 忘记机器人 | ✅ | 本地删除 | 同时删 PIN 与上次地址 |
| C18 | 连接诊断 | ✅（P1） | 本地日志 | 记录状态迁移、重连次数、最近错误；不含 PIN |
| C19 | 手机蓝牙状态 | ✅ | BLE 状态机 | 顶栏「蓝牙」chip、连接页、连接 tab；**与机器人 Wi-Fi 分开显示** |

| D6 | 头部回正 | ✅ | `robot.head {0,0,0,0}` | 按钮 + 超时自动 |

| D15 | wheee 长叫 | ✅ | `robot.sound {tag:"wheee", hold}` | 按住 ~10 Hz 发 `hold:true`，松开发 `hold:false` |
| D16 | 音量 / 静音 | ✅ | `robot.volume`（新增） | 滑杆 0–100、静音、回读；持久化到 ALSA |
| D17 | 状态详情 | ✅ | 状态 + health | 连接、策略、控制环、电源、双温度、输入源、告警摘要 |
| D18 | 维护面板 | ✅ | 状态 + 命令 | 重启舵机、输入源、版本/环频/温度、网络与系统入口、排障 |
| D19 | 告警详情 | ✅ | 本地合成 | 输入源、限幅、电量、倒地、电机温度、主控温度、控制环 |
| D20 | 最近消息 | ✅ | 本地事件 | 时间、级别、标题、摘要；最多 150 条 |
| D21 | 只读态 | ✅ | robotd 标定模式 / 订阅被拒 | 仍可看电量、温度、总线；运动按钮禁用 |
| D22 | 离线态 | ✅ | 本地 | 蓝牙未连接 / 重连失败；重试、打开蓝牙设置、排障 |
| D23 | 停止路径 | ✅ | 见 §5.4 | 按钮、松手、切后台、关页面、断链、进程被杀 |

| D25 | 振动反馈 | ✅（可选） | Android Vibrator | 停下/卸力/错误；不支持时静默 |
| D26 | 双链路状态提示 | ✅ | 本地合成 | 蓝牙已连 + 机器人未联网时黄条「仍可驾驶和配置网络」；蓝牙断链走离线页，不用 Wi-Fi 状态冒充 |
| D27 | 预设动作 | ✅ | `robot.action`（新增） | 抬头 / 左右看 / 画圈 / 张嘴；由 `robotd` 播放并与网页版共用实现；`act` / `actIdle` 随状态帧下发；推摇杆、停止、卸力、倒地立即打断且不回写头角 |

## 3. 网络配置（来自 ducknet，PC 蓝牙改 Wi-Fi）

| N17 | 隐藏网络 | ⬜ | — | 首版不做；扫描列表里没有的 SSID 只支持「忘记」 |

| N21 | 与手机蓝牙状态分离 | ✅ | 两条独立状态 | 顶栏两个 chip；状态页「链路」卡；网络页注明「只改机器人自己的 Wi-Fi」 |

## 6. 本地数据与隐私

| 数据 | 保存方式 | 备注 |
| --- | --- | --- |
| 机器人列表（序列号、名称、上次地址/时间） | 普通偏好 | 序列号是主键，改名不丢 |
| PIN | Android Keystore 加密 | 按序列号保存；可「不记住」 |
| Wi-Fi 密码 | Android Keystore 加密 | 按 SSID 保存；忘记网络时一并删除 |
| 固定 IP | 普通偏好 | 按「序列号 + SSID」保存；与 ducknet 规则一致 |
| 速度档、上次页签 | 普通偏好 | 轻量 |
| 连接诊断日志 | 应用私有目录 | 不含 PIN/PSK；可清空 |
| 告警/最近消息 | 内存 | 重启 App 清空 |

## 7. 首版明确不做

- 摄像头画面、3D 姿态、关节曲线、舵机标定；
- 固件 / 模型升级、恢复出厂、关机、改 PIN；
- 账号登录、云中继、远程访问；
- 地图、轮滑专用盘、多手机抢权；
- 隐藏网络加入、WEP/企业网连接；
- iOS 版本（本机无 macOS 构建环境）。

## 9. 首版优先级

## 10. 验收主线

1. 蓝牙连接：扫描 → PIN → 认证 → 断链重连 → 换机器人。
2. 驾驶：站立 → 接管 → 摇杆/头部 → 停下 → 卸力 → 重启舵机。
3. 策略：列表 → 切换 → 执行 → 门禁。
4. 声音：7 个声音 → wheee 按住 → 音量/静音回读。
5. 网络：状态 → 扫描 → 连接（含错误密码）→ 固定 IP → 忘记。
6. 系统：身份 → 服务 → 日志 → 改名 → 重启。
7. 安全：断链/切后台/杀进程 → 零速；PIN 错误次数；标定模式只读。
8. 共存：BLE 与网页版同时在线时的冲突提示；网页版功能不受影响。
9. 双链路：蓝牙已连 + 机器人未联网时黄条正确；网络页仍可配置 Wi-Fi；蓝牙断链时走离线页，不用 Wi-Fi 状态冒充蓝牙状态。
