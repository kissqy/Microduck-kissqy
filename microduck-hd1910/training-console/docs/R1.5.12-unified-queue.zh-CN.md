# R1.5.12 流程与参数验证

训练统一为“选择参数 → 加入队列 → 开始训练”，单个任务也必须先加入。绿色加入按钮保留在参数标题旁；队列标题旁显示当前实际训练方案，空闲时显示下一项待训方案。删除重复的顶部方案栏、开始队列和暂停后续按钮。

停止训练先禁止并持久化后续调度，再向当前训练发送停止请求；不停止仿真、不关闭WSL，待训条目保留。任务完成事件到进程退出之间点击停止，也不会启动下一项。停止条目仅手动重新训练才会重排。旧R1.5.10/1.5.11后台配新版网页时，同一按钮先暂停调度，再读取最新当前任务并停止，支持只覆盖网页文件更新。

接触面和物理设置位于“本次训练参数”，不放在硬件参数卡片。显示足底摩擦范围、抽样时机、双脚共用抽样、接触维度、接触求解器继承项、接触/约束缓冲、传感器容量、凸碰撞检测迭代、物理步长、BAM摩擦随机倍率、转子惯量和编码器误差范围、地形组成及足底编译读回。中英对照、用途和默认值直接显示；支持既有覆盖路径允许的编辑。已加入的任务和正在训练的任务保留各自快照。

足底范围0.7～1.3和BAM摩擦倍率0.9～1.1是不同的随机化。行走老师接触容量200、倒地起身老师35按所选配方显示；没有自动修改官方值。solref/solimp的配置继承和编译值分开展示。运行配置与编译读回不是实时各环境抽样值，旧记录未采集时明确说明。

并行数支持3072；联合默认6000基准轮换算为8000实际轮，修改回2048为12000轮，继续遵守4096×24基准采样换算。默认并行仍为4096。

## 验证结果

- 22项队列与持久化测试：19项通过，3项依赖运行环境的进程隔离测试跳过。
- Chromium真实HTTP和桌面调度：单项必须排队，接触参数编辑进入快照，当前方案显示正确，两位队列老师完成后取最新PT进入联合训练，关闭浏览器后顺序执行继续，失败重试，统一停止和待训保留。
- R1.5.11旧后台＋R1.5.12静态页面完成同一组队列测试，停止按钮兼容旧后台。
- 联合/V2老师/仿真入口回归通过；3072→8000默认预算读回通过。
- 4K、1920、1280、1024、390宽度无页面横向溢出；参数/课程、奖励区与R17主题检查通过。
- 所有界面流程均无自动probe、preflight、setup或describe；开始训练未调用单项直启接口。
- 35份物理执行器、运行适配、滤波、标定和任务配方文件与R1.5.11字节一致。未改变训练默认物理参数、滤波或课程。

这些是CPU侧调度和浏览器验证，没有在用户电脑重新跑GPU训练，也没有终止用户已有训练。
