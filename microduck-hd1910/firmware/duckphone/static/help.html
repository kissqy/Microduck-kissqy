连不上怎么办

这一页在离线时也能打开（Service Worker 缓存）。按顺序排查，通常第 1、2 步就能解决。

1. 手机和鸭子在同一 Wi-Fi

  • 路由器要允许设备互访；开了「AP 隔离 / 访客网络」就连不上。
  • 手机如果连的是 5 GHz、鸭子连 2.4 GHz，只要在同一个子网就没问题；跨网段不行。
  • 关掉手机上的 VPN / 代理再试。

2. 板子上的 duckphone 在跑

systemctl status duckphone
journalctl -u duckphone -n 50 --no-pager
启动日志里有两样东西：地址和配对码。
地址形如 http://192.168.110.240:8001/，配对码是 6 位数字（也存在 /etc/duckphone/token）。

3. 页面能开、但一直显示未连接

  • 先看 http://<板子IP>:8001/healthz：返回 ok 说明桥正常，robotd-unreachable 说明桥活着但连不上 robotd。
  • systemctl status robotd，再 robotctl health。
  • 桥以 duck 身份运行，需要在 robot 组里（id duck 能看到 robot）。

4. 提示「配对码不对」

  • 配对码每次重装服务不会变，除非手动删掉 /etc/duckphone/token。
  • 连续错 5 次会锁 60 秒，页面会显示倒计时。

5. 能连上但机器人不动

  • 手柄服务在抢控制权。顶部黄条会提示，点「详情」可以直接停掉它。
  • 策略没接管：先点「站立」，再点「接管」。
  • 看「状态详情」里的控制环频率，低于 45 Hz 说明板子忙或散热有问题。
  • 看「未执行」提示里的原因：指令超时 = 摇杆没保持按住或 Wi-Fi 抖动。

6. 手机熄屏后要重新点一次页面

这是浏览器的限制，不是 bug。切后台、熄屏都会让桥在 500 ms 内归零；回来时页面会自动重连，但屏幕常亮需要重新申请。

7. 彻底重启

sudo systemctl restart duckphone

这只重启桥，不影响 robotd 和机器人当前姿态。物理 HUB 上的电源开关是最后手段。
