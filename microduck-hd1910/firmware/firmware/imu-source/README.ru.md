# Исходники отдельного IMU корпуса · текущая FT6

<a id="独立躯干-imu-固件源码--当前-ft6"></a>
<a id="independent-torso-imu-source--current-ft6"></a>
Этот каталог содержит прошивку **самодельного IMU STM32G031F8P6 + LSM6DSV16X**, отдельную от Linux-служб control.43 на ZERO. Текущая конфигурация Feetech HD1910 использует **FT6_SYNC15_UART_IRQ_v1**, фиксированный ID 200 и скорость 1 Mbps.

**Начните со [скачивания IMU, подключения, программирования и проверок](../../../../hardware/IMU-FIRMWARE.ru.md).** Доступен готовый `.bin` размером 8,428 байт; для обычной сборки компиляция не нужна. Полный порядок прошивки определён на той странице.
